item 1 · web

claude.ai/code — el navegador es tu terminal

Te metes a claude.ai/code y ya jala. No instalas nada, no abres terminal, no configuras nada. Te logueas con tu cuenta de Claude (Pro, Max, Team Premium o Enterprise) y ahí está todo: el sidebar de sesiones a la izquierda, el chat al centro y el dropdown del repo al pie. La interfaz se rediseñó en abril 2026 con un sidebar nuevo y mejoras de velocidad y confiabilidad.

  • Cero instalación

    No descargas nada. No abres terminal. Te logueas con tu cuenta de Claude (Pro, Max, Team Premium o Enterprise) y ya estás dentro.

  • Sessions sidebar

    Lista todas tus sesiones activas y recientes en un solo lugar. Filtras por estado, por proyecto o por entorno, y puedes agruparlas. Cuando se mergea el PR, se auto-archiva.

  • Drag-and-drop de archivos

    Arrastras archivos del Finder o del Explorer directo al chat. Útil para mockups, errores en logs, capturas o documentos que quieres que Claude lea.

  • GitHub conectado o repo subido

    Lo normal: instalas la GitHub App de Claude, autorizas tus repos y la sesión clona, edita y pushea sola. Alternativa: sube un repo local hasta 100 MB con CCR_FORCE_BUNDLE=1.

  • Tareas paralelas

    Puedes correr varias sesiones a la vez en distintos repos. Una refactorea, otra arregla un bug, otra escribe tests. Todas viven en el sidebar.

item 2 · celular

Te llega el cliente, sacas el celular, le mandas la tarea

El mismo claude.ai/code abre desde tu navegador móvil. Y si quieres notificaciones push y mejor experiencia, baja la app oficial de Anthropic — Claude Code se incluye dentro. Te llega el cambio del cliente mientras vas en el carro o en la calle, sacas el cel, le picas y le mandas la tarea. Tu sesión sigue en la nube y modifica el repo directo, sin abrir laptop.

  • Apps nativas para iOS y Android

    Claude Code llegó al móvil en octubre 2025. La app oficial de Anthropic ya lo incluye, con soporte de push notifications cuando termina una tarea o necesita tu input.

  • Mismo claude.ai/code en el navegador

    Si no quieres bajar la app, abres el navegador del celular y entras al mismo URL. La interfaz es responsive — el sidebar se colapsa, el input queda al fondo.

  • Lo que jala desde el celular

    Mandar tareas nuevas, monitorear sesiones que dejaste corriendo, ver el diff de lo que cambió, comentar líneas, controlar el auto-fix de PRs y recibir notificaciones.

  • Lo que NO jala desde el celular

    Comandos interactivos tipo /mcp (que abren un picker en terminal) no funcionan en móvil. Los comandos de salida en texto sí — /context, /compact, /recap, /tasks.

Sin app: también te jala desde el navegador del celular abriendo claude.ai/code. Login con la misma cuenta y tus sesiones aparecen igualito que en la compu — solo que el sidebar se colapsa y el input queda al fondo de la pantalla.

item 3 · teleport

claude --teleport — la sesión salta a tu terminal

Empezaste en el celular, llegas a tu compu, abres terminal. Escribes claude --teleport, eliges la sesión y listo: la conversación entera, los archivos editados y la rama checkeada saltan al terminal. Sigues donde te quedaste, pero ahora con todo tu setup local — tu shell, tus aliases, tus dotfiles.

Variantes y dónde correrlas:

  • claude --teleport

    Picker interactivo. Te lista las sesiones nube disponibles para que elijas una. Útil cuando no recuerdas el ID.

  • claude --teleport <session-id>

    Resume directo. Si copiaste el ID desde la web (botón "Open in CLI"), pégalo aquí y ahorra el picker.

  • /teleport o /tp

    Mismo picker pero desde una sesión CLI ya activa. No tienes que reiniciar Claude Code — abres el picker, eliges otra sesión y se cambia.

  • Botón "Open in CLI" en la web

    Desde claude.ai/code, en el menú de la sesión, te copia el comando `claude --teleport <id>` listo para pegar en tu terminal.

Antes de teleportear, valida estos cinco puntos:

  • Login con cuenta claude.ai

    Si entraste a la CLI con API key, Bedrock, Vertex o Foundry, teleport NO jala. Sal y vuelve a entrar con `/login` usando tu cuenta de claude.ai (Pro, Max o superior).

  • Branch ya pusheada

    La rama de la sesión nube debe existir en el remote para que el teleport pueda hacer fetch + checkout. Cuando empiezas en la web, la rama se pushea sola; verifica que sí lo haya hecho antes de teleportear.

  • Working tree limpio

    Si tienes cambios sin commitear, teleport te pide stashear primero. Es buena práctica: `git stash` antes, `git stash pop` después si los necesitas.

  • Mismo repo, no un fork

    Teleport asume que el repo local apunta al mismo origin que la sesión nube. Si trabajas en un fork, el fetch de la branch falla.

  • Solo va nube → terminal

    Teleport es uno-vía: baja sesiones de la web/celular a tu terminal local. Para el flujo opuesto (empezar local y mover a la nube) usas `claude --remote`.

Quiero bajar a mi terminal una sesión que dejé corriendo en claude.ai/code. Guíame paso a paso:

1. Dime cómo encuentro el ID de la sesión desde la web (o si prefieres, abro el picker con `claude --teleport` sin argumentos).
2. Antes de teleportear, valida con `git status` que mi working tree está limpio. Si hay cambios sin commitear, propón si los stasheamos o los committeamos primero.
3. Confirma que la branch de la sesión nube ya está pusheada al remote.
4. Ejecuta el teleport. Cuando ya esté local, muéstrame el resumen de la sesión: cuántos archivos tocó, qué pruebas corrió, qué quedó pendiente.
5. Antes de seguir tirando código, dame un plan de lo que sigue y espera mi OK.

Si algo falla (login con API key en lugar de cuenta, branch no encontrada, working tree sucio), explícame el error en una línea y dame el comando exacto para arreglarlo.

¿Y si el repo no está en GitHub? Para sesiones nube sin GitHub, súbelo bundleado: CCR_FORCE_BUNDLE=1 claude --remote "tu tarea aquí". Sube hasta 100 MB. La sesión nube edita los archivos pero no puede hacer push de regreso, así que el flujo natural es: subir bundleado → terminar el cambio → teleportear al terminal → committear y pushear local.

complemento · control remoto

/remote-control — controla tu terminal desde el celular

Teleport baja la sesión nube a tu terminal local. Remote-control es el opuesto: tu sesión sigue corriendo local en tu compu, pero la controlas desde tu celular o desde claude.ai/code. Útil para cuando saliste, te acuerdas de algo, y no quieres regresar a sentarte frente al teclado.

  • Saliste y te acuerdas de algo

    La sesión sigue corriendo en tu compu. Sacas el celular, mandas el prompt y tu compu lo ejecuta como si estuvieras frente al teclado.

  • Tarea larga sin estar pegado

    Empiezas una tarea pesada en local, te vas. Desde el celular monitoreas el output y respondes los "¿le sigo?" de Claude sin volver a la compu.

  • Aprobar cambios desde la calle

    Tu sesión local te pide confirmación para tocar un archivo crítico. Te llega la notificación al celular, le pones OK desde ahí.

Lo que necesitas confirmado antes de meterle

Cuatro cosas. Si las tienes en orden antes de abrir claude.ai/code, te ahorras todos los errores típicos del primer día. Si no, te vas a frenar en el lugar más obvio: el plan, el repo, la auth, o la versión del CLI.

    Free NO incluye Claude Code. Pro ($20/mes) ya te da web, celular, teleport y remote-control. Max ($100 o $200) suma Opus 4.7 y 5× los rate limits.

    Si tu cuenta es de Team, asegúrate de que el admin haya activado el plan Premium ($100/seat, mínimo 5 seats). Team Standard NO incluye Claude Code.

ojo con esto

Lo que rompe a la gente la primera vez

Estas siete trampas son las que más cuestan tiempo cuando alguien arranca con Claude Code en web o celular. No son bugs — son comportamientos esperados que no son obvios hasta que los chocas. Léelas antes de empezar y te ahorras horas.

  • 1

    API key bloquea teleport y remote-control

    Si entraste con `ANTHROPIC_API_KEY`, Bedrock o Vertex, los flujos web ↔ terminal no funcionan. Sal con `/logout`, vuelve con `/login` usando tu cuenta de claude.ai.

  • 2

    La sesión no se cierra al cerrar el navegador

    Cerrar la pestaña no detiene la sesión. Sigue viva en el sidebar y consume tu rate limit si está trabajando. Archívala o elimínala desde la web cuando termines.

  • 3

    Tu ~/.claude no carga en la nube

    Las sesiones nube clonan el repo, no tu home. Si quieres que cargue tu CLAUDE.md o tu .claude/settings.json, deben estar committeados al repo (no solo en tu carpeta de usuario).

  • 4

    Setup script con error mata la sesión

    Si configuras un setup script y un comando devuelve exit ≠ 0, la sesión nube no arranca. Para pasos no críticos usa `|| true` para que no rompa el flujo.

  • 5

    Repos local-only se pueden subir bundleados

    Si no usas GitHub, súbelos con `CCR_FORCE_BUNDLE=1 claude --remote "tarea"` (límite 100 MB). Ojo: sin GitHub, la nube NO puede hacer push de regreso.

  • 6

    Rate limits compartidos

    Correr varias sesiones nube en paralelo no te cobra extra, pero sí consume tu cuota más rápido. Si llegas al techo, una sola tarea más te bloquea hasta que reinicie la ventana.

  • 7

    Comandos interactivos no jalan en celular

    /mcp y comandos similares que abren un picker en terminal no aparecen bien en el móvil. Quédate con los comandos de texto (/context, /compact, /recap) cuando andes en el cel.

Regla general: si algo no jala, primero confirma con qué cuenta entraste (cuenta claude.ai vs API key), después confirma el plan, después confirma el estado de git. El 80% de los problemas se resuelven en esos tres puntos.

¿Para quién no es Claude Code en web?

Si estás en el plan Free, todavía no jala — necesitas Pro mínimo. Si trabajas con repos super privados que no puedes conectar a una GitHub App, el camino bundleado (CCR_FORCE_BUNDLE) te limita a 100 MB y sin push automático. Y si dependes de comandos interactivos del CLI (pickers, MCPs locales), esos van a vivir solo en tu terminal — la web los reemplaza por interfaz gráfica, pero algunos no tienen equivalente todavía.

¿Y si nunca has usado Claude Code?

Empieza por el web — es el camino más corto. Login en claude.ai/code, conecta un repo, manda un prompt simple. Cuando le agarres el ritmo, instala el CLI con npm install -g @anthropic-ai/claude-code y prueba el teleport. En ese orden te equivocas menos.
