Agencia Digital Completa

una biblioteca de 900+ habilidades (skills) listas para instalar en tu agente de IA. como darle superpoderes a Claude Code, Cursor, Gemini CLI y más — sin configurar nada a mano.

Qué es esto

antigravity-awesome-skills es un repositorio con 978+ archivos markdown de instrucciones. cada archivo le enseña a tu agente de IA a hacer una tarea específica — desde arquitectura de software hasta estrategias de negocio, seguridad, testing y workflows de desarrollo.

piensa en cada skill como contratar un consultor experto bajo demanda. tu agente los lee automáticamente y los usa cuando son relevantes para lo que estás haciendo.

Para quién es

cualquier persona que use Claude Code, Cursor, Gemini CLI u otro agente compatible. no necesitas experiencia en código para instalar y usar los skills — un solo comando y listo.

Cómo instalar

abre tu terminal en la carpeta de tu proyecto y corre el comando según tu herramienta:

Claude Code

npx antigravity-awesome-skills --claude
Copiar comando

Cursor

npx antigravity-awesome-skills --cursor
Copiar comando

Gemini CLI

npx antigravity-awesome-skills --gemini
Copiar comando

el instalador te deja elegir qué categorías instalar. no necesitas instalar las 900+.

Cómo usar un skill

una vez instalados, usa la sintaxis @skill-name para activar un skill específico en tu prompt. ejemplos:

"@api-design diseña la API para mi app de pedidos"
"@security-audit revisa este endpoint por vulnerabilidades"
"@pricing-strategy ayúdame a definir precios para mi SaaS"
"@test-generation genera tests para este módulo"

Categorías de skills

los 978+ skills están organizados en 9 categorías principales:

Arquitectura

diseño de sistemas, patrones, microservicios, APIs

Negocio

pricing, monetización, estrategia, go-to-market

Data & IA

pipelines de datos, ML, embeddings, RAG

Desarrollo

frontend, backend, APIs, debugging, refactoring

General

documentación, comunicación, productividad

Infraestructura

deploy, CI/CD, Docker, Kubernetes, cloud

Seguridad

auditorías, auth, OWASP, pentesting, compliance

Testing

unit tests, integration, e2e, TDD, coverage

Workflow

git, code review, project management, automatización

Tips

  • no instales todo — elige 2-3 categorías relevantes para tu proyecto actual.
  • los skills se instalan por proyecto, no globalmente. cada proyecto puede tener los suyos.
  • puedes volver a correr el instalador para agregar más categorías después.
