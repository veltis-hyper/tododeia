02 supadata

Supadata — Ve y entiende cualquier video

Qué es esto (explicación simple)

Imagina que Claude pudiera ver cualquier video de YouTube, TikTok, Instagram o cualquier red social. Supadata es exactamente eso — una API que transcribe videos completos y te da las métricas (vistas, likes, comentarios). Le das un link y Claude obtiene todo el contenido del video en texto, listo para analizar.

Para qué lo usamos

  • Analizar videos de la competencia — qué dicen, cómo lo dicen, qué funciona
  • Entender la estructura de videos virales en cualquier nicho
  • Extraer ideas y puntos clave de tutoriales o conferencias
  • Ver las métricas de cualquier video sin abrir la plataforma

Paso 1: Obtener tu API key

  1. Ve a supadata.ai y crea una cuenta
  2. En tu dashboard, copia tu API key

Paso 2: Configurar en tu .mcp.json

Abre (o crea) el archivo .mcp.json en la raíz de tu proyecto y agrega esto:

{
  "mcpServers": {
    "supadata": {
      "command": "npx",
      "args": ["-y", "supadata-mcp"],
      "env": {
        "SUPADATA_API_KEY": "tu-api-key-aqui"
      }
    }
  }
}

O instalar con npx directamente

npx -y supadata-mcp
Copiar comando

Después de agregar, reinicia Claude Code

Escribe /mcp para verificar que Supadata aparece como servidor conectado. Ahora Claude puede transcribir y analizar videos.

03 apify

Apify — Busca y extrae datos de toda la internet

Qué es esto (explicación simple)

Imagina que le das a Claude un robot que puede visitar cualquier página web y extraer toda la información. ¿Quieres saber qué está publicando tu competencia en Instagram? Apify lo encuentra. ¿Necesitas los precios de un producto en 10 tiendas diferentes? Apify los extrae. Es la herramienta de scraping más poderosa que existe, y con su MCP, Claude la usa directamente.

Para qué lo usamos

  • Scraping de redes sociales — posts, seguidores, engagement
  • Monitorear precios y productos de la competencia
  • Extraer datos de cualquier página web de forma masiva
  • Buscar leads, emails, información de contacto

Paso 1: Obtener tu API token

  1. Ve a apify.com y crea una cuenta
  2. En Settings > Integrations, copia tu API token

Paso 2: Configurar en tu .mcp.json

Agrega esto a tu archivo .mcp.json:

{
  "mcpServers": {
    "apify": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-apify"],
      "env": {
        "APIFY_TOKEN": "tu-api-token-aqui"
      }
    }
  }
}

O instalar directamente

npx -y @anthropic-ai/mcp-apify
Copiar comando

Después de agregar, reinicia Claude Code

Escribe /mcp para verificar que Apify aparece conectado. Apify tiene cientos de "actors" (scrapers pre-hechos) para Instagram, TikTok, Google, Amazon y más.

04 last 30 days

Last 30 Days — Tu investigador experto de IA

Qué es esto (explicación simple)

Imagina que tienes un investigador personal que lee todas las noticias de los últimos 30 días sobre cualquier tema. Le dices "investiga qué pasó en el mundo de agentes de IA" y te regresa un reporte completo con las noticias más importantes, links y un resumen ejecutivo. Es un skill de Claude Code que convierte a Claude en un experto investigador de cualquier nicho.

Para qué lo usamos

  • Mantenerte al día con las últimas noticias de IA
  • Investigar tendencias de cualquier industria o nicho
  • Generar reportes de investigación para clientes
  • Encontrar oportunidades y cambios en tu mercado

Cómo instalarlo

Este es un skill de Claude Code. Se instala con un solo comando:

Instalar Last 30 Days skill

claude install-skill https://github.com/mvanhorn/last30days-skill
Copiar comando

No necesita API key ni configuración extra

Una vez instalado, simplemente pídele a Claude que investigue cualquier tema. El skill usa búsqueda web para encontrar las noticias más relevantes de los últimos 30 días y te las organiza.

05 playwright

Playwright CLI — Dale a Claude su propio navegador

Qué es esto (explicación simple)

Imagina que le das a Claude su propia computadora con un navegador. Puede abrir páginas, hacer clic en botones, llenar formularios, tomar screenshots y navegar la web como si fuera una persona. La ventaja sobre la integración de Chrome que trae Claude es que Playwright usa muchísimos menos tokens — es más rápido, más eficiente y te ahorra dinero.

Para qué lo usamos

  • Investigar páginas web y extraer información visual
  • Testear aplicaciones web automáticamente
  • Tomar screenshots de cualquier página
  • Llenar formularios y automatizar flujos web

Paso 1: Instalar Playwright globalmente

Primero instalamos la herramienta y después descargamos el navegador Chromium:

Instalar Playwright CLI

npm install -g @anthropic-ai/claude-code-playwright
Copiar comando

Instalar el navegador Chromium

npx playwright install chromium
Copiar comando

Paso 2: Configurar en tu .mcp.json

Agrega esto a tu archivo .mcp.json:

{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/claude-code-playwright"]
    }
  }
}

Después de agregar, reinicia Claude Code

Escribe /mcp para verificar que Playwright aparece conectado. Ahora Claude tiene su propio navegador.

06 todo junto

Los 4 superpoderes trabajando juntos

Ya tienes los 4 superpoderes instalados. Cada herramienta sola es útil, pero juntas son otra cosa. Aquí te muestro cómo combinarlas:

El flujo completo

1. Transcribe

Supadata extrae el contenido de los videos

2. Scrapea

Apify extrae datos de cualquier página web

3. Investiga

Last 30 Days te da las últimas noticias del nicho

4. Navega

Playwright visita páginas y toma screenshots

Ejemplo 1: Análisis de competencia completo

Combina Supadata + Apify para analizar toda la estrategia de contenido de un competidor.

Copiar
Usa Supadata para transcribir los últimos 5 videos de [canal de YouTube]. Después usa Apify para encontrar sus redes sociales y extraer sus últimos 20 posts de Instagram. Analiza: qué temas cubren, qué formato de contenido les funciona mejor, cuáles son sus calls to action, y dame un reporte con recomendaciones para crear contenido que compita directamente.

Ejemplo 2: Investigación de mercado + tendencias

Combina Last 30 Days + Supadata para entender las tendencias actuales de un nicho.

Copiar
Usa Last 30 Days para investigar qué ha pasado en los últimos 30 días en el mundo de [tu nicho]. Después usa Supadata para transcribir los 3 videos más populares de ese tema en YouTube esta semana. Compara lo que dicen las noticias con lo que dicen los creadores de contenido y dame un reporte con las oportunidades que identificas.

Ejemplo 3: Auditoría web con navegador

Combina Playwright + Apify para investigar la presencia web de cualquier empresa.

Copiar
Usa Playwright para abrir la página de [competidor.com], toma screenshots de su landing page, su pricing y su about page. Después usa Apify para encontrar todas sus redes sociales y extraer sus últimos posts. Dame un análisis completo de su presencia digital — qué están haciendo bien, qué pueden mejorar, y cómo podemos posicionarnos mejor.

El poder está en la combinación

Cada herramienta sola es útil. Pero cuando las combinas, Claude se convierte en un investigador completo — puede ver videos, leer noticias, scraping de datos y navegar la web. Todo desde tu terminal.

07 tips

Tips para mejores resultados

Sé específico con los links

En vez de "analiza a mi competencia", dale los links exactos: "transcribe este video: [URL], y después scrapea esta cuenta: [URL]".

Usa Plan Mode para tareas grandes

Presiona Shift+Tab antes de pedir algo complejo. Claude planea primero qué herramientas usar y en qué orden, y después ejecuta con precisión.

Playwright ahorra tokens

Si solo necesitas ver una página web, usa Playwright en vez de la integración de Chrome. Es más rápido y consume menos tokens de tu plan.

Combina explícitamente

Dile a Claude exactamente qué herramientas usar: "usa Supadata para el video y Apify para las redes". Así sabrá exactamente qué hacer.
