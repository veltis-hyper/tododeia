01 qué es

Tu estudio de video con IA

Imagínate que le puedes decir a tu computadora: "hazme un video de 30 segundos anunciando mi producto" y ella lo hace sola. Eso es Editor Pro Max. Una herramienta open source que convierte a Claude Code en un estudio completo de edición de video.

Describe

Le dices a Claude qué video necesitas en español, como si hablaras con un editor humano.

Genera

Claude escribe código Remotion que crea el video con animaciones, texto, transiciones y más.

Exporta

Renderizas un MP4 profesional listo para subir a TikTok, YouTube, Instagram o cualquier plataforma.

No necesitas experiencia

No necesitas saber de edición de video, After Effects ni programación. Solo describes lo que quieres y Claude lo construye. Lo que apps te cobran mensual, lo haces gratis en tu computadora.

02 el flujo

De texto a video en 4 pasos

01

Instala

Clonas el repositorio, instalas dependencias con npm y abres Claude Code. El repo ya viene con 8 AI Skills preconfigurados que le dan a Claude conocimiento experto en video.

02

Describe

Le dices a Claude qué video quieres: el tipo de contenido, la duración, el estilo visual y para qué plataforma es. En español, como si hablaras con un editor humano.

03

Preview

Claude genera el código Remotion automáticamente y lo previsualizas en tu navegador en tiempo real. Puedes iterar: pedirle cambios, ajustar colores, textos o animaciones.

04

Render

Cuando estés conforme, renderizas el MP4 final con las dimensiones exactas de tu plataforma. Puedes hasta generar múltiples versiones para diferentes redes sociales de un solo golpe.

100% local

Todo el procesamiento es local. La transcripción con Whisper.cpp, el procesamiento de video con FFmpeg, la remoción de fondos — todo corre en tu máquina. No se sube nada a ningún servidor externo. Tu contenido se queda contigo.

06 instalación

Instala Editor Pro Max

Requisitos

  • Node.js 20+ (LTS)
  • Claude Code instalado en tu terminal
  • FFmpeg (opcional — para procesar video existente)
  • Whisper.cpp (opcional — para subtítulos automáticos)

1. Clonar el repositorio

git clone https://github.com/Hainrixz/editor-pro-max.git
Copiar comando

2. Instalar dependencias

cd editor-pro-max && npm install
Copiar comando

3. Abrir Claude Code e iniciar

claude
Copiar comando

4. Iniciar el preview en el navegador

npm run dev
Copiar comando

Verificación

Después de correr npm run dev, abre tu navegador en http://localhost:3000. Deberás ver el Remotion Studio donde previsualizas tus composiciones de video.

FFmpeg y Whisper son opcionales

Si algo falla con FFmpeg o Whisper.cpp, no te preocupes. Son dependencias opcionales para funciones avanzadas como subtítulos y remoción de silencios. El core de creación de video funciona sin ellas.

07 en la práctica

Prompts para empezar

Estos son prompts reales que puedes copiar y usar directamente en Claude Code con Editor Pro Max. Personaliza lo que está entre corchetes con tu información.

Crear un TikTok desde cero

Genera un video vertical listo para TikTok con animaciones profesionales.

Copiar
Crea un TikTok de 30 segundos para promocionar [mi producto/servicio]. Estilo: moderno y dinámico. Incluye texto animado con el nombre del producto, 3 beneficios principales con iconos, y un call-to-action final. Usa colores [especifica colores de tu marca]. Formato 9:16 para TikTok.

Agregar subtítulos a un video existente

Transcribe y agrega subtítulos automáticos con estilo personalizado.

Copiar
Tengo un video en [ruta/al/video.mp4]. Necesito agregarle subtítulos automáticos. Usa el preset "bold" para que los subtítulos se vean grandes y con contraste. Transcribe el audio con Whisper y sincroniza los subtítulos con el habla.

Presentación profesional

Convierte un guión en una presentación animada para YouTube.

Copiar
Crea una presentación de 2 minutos sobre [tema]. Formato 16:9 para YouTube. Estructura: intro con título animado, 5 slides con puntos clave, cada slide con transición suave, y un cierre con logo y contacto. Estilo: minimalista, fondo oscuro, texto blanco con acentos en [color de marca].

Limpiar un video (silencios y jump cuts)

Elimina silencios y aplica jump cuts automáticos.

Copiar
Tengo un video largo en [ruta/al/video.mp4]. Necesito:
1) Detectar y eliminar todos los silencios mayores a 0.5 segundos.
2) Aplicar jump cuts automáticos para que quede solo el habla.
3) Exportar el resultado como MP4 para YouTube (16:9).

Experimenta y aprende
