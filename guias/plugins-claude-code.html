la idea

¿Qué es un plugin de Claude?

Un plugin es como una app para tu Claude Code: un paquetito que le agrega habilidades, comandos o herramientas que no traía de fábrica. No cambias nada de tu computadora ni escribes código —solo lo instalas y Claude empieza a hacer cosas nuevas.

Claude Code es muy bueno tal cual, pero genérico. Los plugins lo afilan para lo que tú haces: uno lo vuelve mejor probando, otro mejor diseñando, otro le da ojos para navegar la web. Por eso se dice que sin plugins lo estás usando a la mitad.

Habilidades

Le enseñan a Claude a hacer algo nuevo: probar tu código, diseñar mejor, depurar solo.

Comandos

Atajos que escribes con “/” para lanzar una tarea, como /ralph-loop.

Herramientas

Conexiones a cosas de afuera, como el navegador o documentación al día.

Ojo: los plugins son de Claude Code (la versión que corre en tu terminal o tu editor). Si todavía no lo tienes, instálalo primero; después vuelves aquí a sumarle superpoderes.

paso a paso

Cómo se instalan: el directorio y 3 pasos

Todos los plugins viven en un mismo lugar: el directorio oficial de Anthropic. Lo abres en la web en claude.com/plugins —ahí buscas, ves cuántas instalaciones tiene cada uno y cuáles trae el sello “Anthropic verified”— o directo dentro de Claude Code escribiendo /plugin.

  1. Encuéntralo. En claude.com/plugins busca el plugin que quieres y abre su página (o usa el buscador del comando /plugin).
  2. Copia el comando. Cada plugin trae su comando de instalación, casi siempre con esta forma: nombre@claude-plugins-official.
  3. Pégalo y Enter. Lo pegas en Claude Code, das Enter y se instala solo. Luego corres /reload-plugins para activarlo sin reiniciar.

los imprescindibles

Los 5 que le faltan a tu Claude

Estos son los cinco que más cambian la experiencia, en orden: primero que Claude programe con método, luego que diseñe bonito, que pueda navegar, que no se rinda, y que siempre use documentación al día. Cada uno trae su comando exacto para copiar y pegar.

01

Superpowers

Como tener un programador senior sentado a tu lado.

Le instala a Claude una colección de habilidades de desarrollador con experiencia: hace pruebas de lo que construyes para que nada se rompa, caza errores él solo y te propone ideas y un plan antes de ponerse a programar. Deja de improvisar y trabaja con método.

Instálalo desde el directorio oficial

/plugin install superpowers@claude-plugins-official
Copiar comando

Cómo usarlo: Pídele que haga una lluvia de ideas o que planee antes de construir; las habilidades se activan solas cuando hacen falta.

02

Frontend Design

Le quita a Claude el diseño genérico de IA.

Hace que todo lo que Claude diseña no parezca plantilla de inteligencia artificial: tipografía con criterio, animaciones, jerarquía y profundidad de verdad. No tienes que invocarlo —se activa solo cuando le pides una pantalla, una landing o un componente.

Instálalo desde el directorio oficial

/plugin install frontend-design@claude-plugins-official
Copiar comando

Cómo usarlo: Solo pide tu interfaz como siempre ('hazme una landing para…'); el diseño mejora sin que hagas nada más.

Ver en el directorio oficial
03

Playwright

Le da a Claude el control de tu navegador.

Con Playwright, Claude maneja un navegador de verdad: abre páginas, da clics, llena formularios, toma capturas de pantalla y prueba flujos completos de principio a fin, sin que tú toques el mouse. Ideal para probar lo que estás construyendo.

Instálalo con este comando

claude mcp add playwright npx @playwright/mcp@latest
Copiar comando

Cómo usarlo: Pídele que abra una página y haga la tarea ('entra a mi sitio y llena el formulario de contacto'); él controla el navegador.

Ver en GitHub · microsoft/playwright-mcp
04

Ralph Loop

Vuelve a Claude necio: no para hasta terminar.

A veces Claude se desvía o deja una tarea a medias. Ralph Loop lo hace necio en el buen sentido: repite la misma tarea una y otra vez, guardando los cambios entre intentos, hasta cumplirla como tú la pediste. No se le olvida hasta que la termina.

Instálalo desde el directorio oficial

/plugin install ralph-loop@claude-plugins-official
Copiar comando

Cómo usarlo: Luego lo lanzas así: /ralph-loop "tu tarea aquí" --max-iterations 10 --completion-promise "DONE"

Ver en el directorio oficial
05

Context7

Se acabó el Claude que se inventa el código.

Context7 le inyecta a Claude la documentación más reciente de las herramientas que uses, directo desde la fuente. Así no escribe código con funciones que ya no existen ni se inventa cosas: usa lo que de verdad está vigente hoy.

Instálalo con este comando

npx ctx7 setup
Copiar comando

Cómo usarlo: El setup te pide login y crea tu API key gratis. Después solo agrega "use context7" al final de tu prompt (ej: "cómo configuro Next.js 16, use context7").

más allá de los 5

Cómo encontrar más (y usarlos seguro)

Los cinco de arriba son el mejor punto de partida, pero hay cientos. Dentro de Claude Code, el comando /plugin abre un gestor con cuatro pestañas: Discover (explorar), Installed (los que ya tienes), Marketplaces y Errors. Ahí buscas, instalas y prendes o apagas cualquiera.

Además del catálogo oficial, puedes agregar otros “marketplaces” (catálogos de la comunidad) con un comando. Por ejemplo, el de Superpowers, que trae más herramientas del mismo autor:

Agregar otro catálogo de plugins (ejemplo)

/plugin marketplace add obra/superpowers-marketplace
Copiar comando

Un detalle útil: los comandos que trae un plugin llevan su nombre adelante, así no se confunden. Por ejemplo, los de Superpowers se ven como /superpowers:brainstorm.

Instala solo de fuentes que conozcas. Un plugin puede ejecutar código en tu computadora con tus permisos, igual que cualquier programa que instalas. Los del directorio oficial y los “Anthropic verified” son la apuesta segura; con los de la comunidad, revisa quién los hace antes de darle instalar. Si quieres entender bien permisos y control, lee la guía de seguridad en Claude.
No los instales todos. Cada plugin le suma información a Claude en cada mensaje (ocupa “contexto”). Quédate con los que de verdad usas; los demás los puedes apagar con /plugin disable y prender cuando los necesites.

dudas rápidas

Preguntas frecuentes

¿Necesito saber programar para instalarlos?

No. Instalarlos es copiar un comando, pegarlo y dar Enter. Lo único que necesitas es tener Claude Code abierto.

¿Cuestan dinero?

Los del directorio oficial son gratis. Context7 funciona con una API key gratis que se crea sola en su setup; solo pagas si quieres límites más altos.

¿Funcionan en la app de Claude o solo en la terminal?

Los plugins son de Claude Code: corren en tu terminal o en tu editor (VS Code, etc.), no en el chat normal de la app.

¿Se actualizan solos?

Los marketplaces oficiales se actualizan solos al iniciar. Si algo cambia, Claude te avisa para correr /reload-plugins.

¿Puedo quitar uno si no me sirve?

Sí. Lo apagas sin borrarlo con /plugin disable, o lo quitas del todo con /plugin uninstall. Sin enredos.

Cierre de la guía

No instales los cinco de golpe. Empieza con el que más te haga falta —si construyes interfaces, Frontend Design; si quieres que Claude pruebe solo, Superpowers— y suma los demás cuando les agarres el modo. Cada uno es un comando que copias, pegas y listo. Esta guía vive en la bóveda de tododeia.
