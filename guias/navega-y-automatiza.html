01 qué son

¿Qué son estas herramientas?

Imagina que Claude es super inteligente pero vive encerrado en una caja. Puede pensar, escribir y resolver problemas — pero no puede ver internet ni tocar nada afuera. Con estas dos herramientas gratis le das ojos y manos.

Firecrawl = Los ojos

Le permite leer cualquier página web. Tú le pasas un link y Claude lee todo el contenido como si fuera una persona. Funciona hasta en páginas que bloquean bots. Es gratis con la cuenta básica.

Playwright = Las manos

Le permite navegar como persona real: hacer clic en botones, llenar formularios, hacer scroll, tomar capturas de pantalla. Es como darle un mouse y un teclado a Claude.

Juntas son imparables. Claude puede ir a cualquier página, leer todo, hacer clic donde necesite, sacar información, llenar cosas por ti y hasta entrar a herramientas web que normalmente no puede usar. Imagina todas las posibilidades.

02 firecrawl

Instala Firecrawl

Firecrawl convierte cualquier página web en texto limpio que Claude puede leer. Vas a crear una cuenta gratis, copiar tu llave y decirle a Claude que la instale.

1. Crea tu cuenta

Ve a firecrawl.dev y regístrate gratis

2. Copia tu API Key

En tu dashboard busca la llave que empieza con fc-...

3. Instala en Claude

Pega el comando de abajo en tu terminal

Instalar Firecrawl en Claude Code

claude mcp add firecrawl-mcp-server -e FIRECRAWL_API_KEY=tu-api-key-aqui -- npx -y firecrawl-mcp-server
Copiar comando
Nota: Reemplaza tu-api-key-aqui con la llave que copiaste de tu dashboard. El plan gratis te da 500 créditos al mes — más que suficiente para empezar.
¿Cómo sé que ya quedó? Abre Claude Code y dile: "Lee la página firecrawl.dev y dime de qué se trata". Si te da un resumen, ya está instalado.

03 playwright

Instala Playwright CLI

Playwright le da a Claude un navegador real. Puede hacer clic, escribir, navegar entre páginas y tomar capturas de pantalla. La instalación es un solo comando.

Instalar Playwright en Claude Code

claude mcp add playwright -- npx -y @anthropic-ai/playwright-mcp@latest
Copiar comando
Dato importante: Playwright es 100% gratis y no necesita API key ni cuenta. Se instala y ya. Así de fácil.
¿Cómo sé que ya quedó? Dile a Claude: "Abre google.com y toma una captura de pantalla". Si ves la imagen, ya tienes Playwright funcionando.

04 primera automatización

Tu primera automatización

Ya tienes las dos herramientas instaladas. Ahora vamos a probarlas con algo real y útil que puedes hacer ahorita mismo.

Investigar una página web

Pídele a Claude que lea y resuma cualquier sitio — tu competencia, un artículo, lo que sea.

Copiar

1. De qué se trata el negocio
2. Qué servicios o productos ofrecen
3. Cómo se posicionan (qué lenguaje usan)
4. Qué podría mejorar su página

Navegar y extraer datos

Deja que Claude navegue por ti como si fuera una persona real.

Copiar
Abre [URL], busca [término] y dame una lista de los primeros 5 resultados con su título y enlace.
Tip: Empieza con cosas simples. Conforme veas lo que Claude puede hacer, vas a ir encontrando automatizaciones cada vez más útiles para tu trabajo diario.

05 ideas

Ideas para automatizar tu trabajo

Aquí tienes ideas listas para que las copies y adaptes. Cada una usa Firecrawl, Playwright o las dos juntas. Nada más dile a Claude qué quieres hacer.

Investigar competencia

Lee las páginas de tus competidores, compara precios, analiza su copy y encuentra oportunidades que ellos están dejando pasar.

Extraer datos de redes sociales

Jala información pública de perfiles de Instagram, Facebook o LinkedIn para análisis de mercado o inspiración de contenido.

Llenar formularios

Deja que Claude llene solicitudes, registros o formularios repetitivos por ti. Tú le das los datos y él hace el trabajo aburrido.

Monitorear precios

Revisa precios de productos en tiendas online y que te avise cuando bajen. Perfecto para compras inteligentes o análisis de mercado.

Jalar datos de cualquier página

Extrae tablas, listas, contactos o cualquier dato estructurado de sitios web. Claude lo lee y te lo organiza como tú quieras.

Trabajar dentro de tus herramientas

Navega tu CRM, tu dashboard de ads o cualquier herramienta web que uses diario. Claude entra y trabaja dentro de todas ellas por ti.

Estas herramientas son el primer paso para que Claude trabaje en internet por ti. Combinadas con habilidades (skills) de Claude Code, puedes automatizar flujos completos de trabajo. Ahora sí puedes automatizar cualquier cosa.
