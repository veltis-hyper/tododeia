Obsidian + Claude

Usa Obsidian como la memoria permanente de Claude — archivos Markdown nativos que Claude lee sin traducción.

Piénsalo así

Imagina que hablas español de nacimiento. No necesitas diccionario, no traduces en tu cabeza — simplemente entiendes. Ahora imagina que Claude "habla" Markdown de nacimiento. Los archivos .md son su idioma nativo. Obsidian guarda TODO como archivos Markdown. Cuando Claude abre tu vault de Obsidian, es como leer en su lengua materna — sin conversión, sin traducción, sin perder nada.

El problema

Claude olvida todo entre sesiones. Cada conversación nueva = pizarra en blanco.

La solución

Un vault de Markdown que persiste en tu computadora y Claude puede leer siempre.

El resultado

Memoria permanente sin gastar contexto. Claude retoma donde lo dejaron.

01 el problema

Claude olvida todo

Claude no tiene memoria entre sesiones. Cada nueva conversación es una pizarra en blanco. Todo el contexto que le diste ayer — las decisiones, el código, los archivos que revisaron juntos — desapareció.

Sin memoria

  • Repites el mismo contexto cada sesión
  • La ventana de contexto se llena rápido
  • Pierdes eficiencia re-explicando todo
  • Claude no aprende de sesiones anteriores

Con Obsidian

  • Claude lee tus notas al empezar
  • Ahorras contexto (no repites info)
  • Recuerda proyectos y decisiones pasadas
  • Construye conocimiento acumulado

Piénsalo así: La ventana de contexto es como la memoria de trabajo (RAM). Obsidian es como el disco duro. No gastas RAM recordando cosas que ya están en el disco.

02 la solución

Obsidian como memoria

Obsidian es una app gratuita que guarda todo como archivos .md en tu computadora. No es cloud obligatorio, no hay vendor lock-in. Tus datos son tuyos.

Archivos Markdown

Claude los lee nativamente, sin plugins ni conversiones. Es su formato nativo.

100% local

Tus datos quedan en tu computadora, no en servidores de terceros.

Gratis

Sin suscripción para las funciones que necesitas. Sync y publish son opcionales.

Wikilinks

Conecta notas entre sí con [[enlaces]] — Claude entiende estas conexiones y navega entre ellas.

¿Por qué Markdown importa? Claude fue entrenado con millones de archivos Markdown. Es su formato nativo. No necesita "traducir" de Word, PDF o Notion. Un archivo .md entra directo a su comprensión — como leer en tu idioma nativo.

03 instalación

Instalación

Cuatro pasos y estás listo.

1Descarga Obsidian

Descárgalo gratis desde obsidian.md. Disponible para Mac, Windows, Linux, iOS y Android.

2Crea un vault

Al abrir Obsidian por primera vez te pedirá crear un vault. Es simplemente una carpeta en tu computadora donde se guardarán todas tus notas.

3Instala obsidian-skills

Esto le enseña a Claude a escribir en formato Obsidian nativo. Son 5 habilidades: Markdown con wikilinks, bases de datos, canvas visual, CLI de Obsidian y extracción de contenido web.

Instalar obsidian-skills

claude install-skill https://github.com/kepano/obsidian-skills
Copiar comando

Alternativa manual: descarga el repositorio y copia su contenido en la carpeta /.claude dentro de tu vault.

4Abre Claude Code desde tu vault

Claude Code ahora tiene acceso a todas tus notas. Puede leer, crear y actualizar archivos en tu vault.

Abrir Claude en tu vault

cd ~/tu-vault-de-obsidian && claude

04 configuración

Configurar CLAUDE.md

Este es el paso más importante. Tu CLAUDE.md le dice a Claude cómo usar tu vault. Sin este archivo, Claude no sabe que debe guardar información ahí.

Crea este archivo en la raíz de tu vault de Obsidian.

Claude lo lee automáticamente cada vez que abres una sesión desde esa carpeta.

CLAUDE.md para tu vault

Copia este contenido y guárdalo como CLAUDE.md en la raíz de tu vault de Obsidian.

Copiar
# Vault de Conocimiento

## Propósito
Este vault es mi base de conocimiento personal. Toda información relevante debe guardarse aquí como notas Markdown.

## Convenciones para crear notas
- Usa wikilinks [[nombre-de-nota]] para conectar conceptos relacionados
- Una idea por nota (notas atómicas)
- Usa aliases en el frontmatter cuando una nota tiene varios nombres
- Usa block references (^id) para citar secciones específicas
- Nombres de archivo en kebab-case: mi-nota-importante.md
- Frontmatter YAML con tags y fecha de creación

## Estructura de carpetas
- /proyectos — notas por proyecto activo
- /conceptos — definiciones y explicaciones
- /referencias — información de fuentes externas
- /diario — notas de trabajo diarias

## Reglas
- SIEMPRE guarda un resumen al terminar una sesión de trabajo
- SIEMPRE revisa notas existentes antes de crear duplicados
- Conecta notas nuevas con notas existentes usando wikilinks
- Actualiza STATE.md con el estado actual del proyecto activo

05 prompts

Prompts esenciales

Estos prompts los usas directo en Claude Code (tu terminal). Asegúrate de estar dentro de tu vault.

Guarda un resumen del proyecto

Úsalo al terminar una sesión para que Claude no olvide lo que hicieron.

Copiar
Guarda un resumen de lo que hicimos hoy en mi vault. Crea una nota en /diario con la fecha de hoy, los cambios principales, decisiones tomadas y lo que queda pendiente. Conecta con wikilinks a las notas de proyecto relevantes.

Revisa contexto antes de empezar

Copiar

Actualiza el estado del proyecto

Mantiene un archivo STATE.md siempre al día con el progreso real.

Copiar
Actualiza el STATE.md del proyecto con lo que hicimos en esta sesión. Incluye: fase actual, tareas completadas, tareas pendientes, decisiones importantes y cualquier bloqueo. Usa el formato que ya tiene el archivo.

Crea notas conectadas

Para cuando descubres conceptos nuevos que vale la pena documentar.

Copiar
Crea notas individuales en /conceptos para cada concepto nuevo que vimos hoy. Cada nota debe tener una explicación simple, un ejemplo práctico y wikilinks a conceptos relacionados que ya existan en mi vault.

06 tips y recursos

Tips y recursos

Abre Claude desde el vault

Siempre ejecuta cd tu-vault && claude. Si abres Claude desde otra carpeta, no tendrá acceso a tus notas.

STATE.md es tu ancla

Mantén un STATE.md por proyecto con el estado actual. Es lo primero que Claude debe leer al empezar.

Notas atómicas

Una idea por nota. Es más fácil para Claude encontrar y conectar información en notas cortas que en documentos enormes.

Revisa antes de crear

Pídele a Claude que revise notas existentes antes de crear nuevas. Evita duplicados y mantiene tu vault limpio.
