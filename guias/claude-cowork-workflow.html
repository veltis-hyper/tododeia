Claude Cowork & Workflow

El espacio donde Claude ya te conoce. Crea proyectos, dale contexto, programa tareas y deja que trabaje mientras tú no estás.

Qué vas a aprender

  • Proyectos en Cowork — cómo crear espacios de trabajo donde Claude mantiene contexto separado
  • Instrucciones de proyecto — cómo escribir reglas que moldean el comportamiento de Claude
  • Contexto inteligente — cómo agregar carpetas, archivos y páginas web
  • Tareas programadas — cómo automatizar acciones recurrentes (la función más poderosa)
  • Keep Awake — cómo mantener tu computadora activa para que las tareas se ejecuten sin ti

01 el problema

Tener que explicar todo de nuevo

Si cada vez que abres Claude le tienes que explicar tu vida completa — quién eres, qué haces, cómo quieres que responda — estás perdiendo tiempo.

Cowork resuelve esto. Es un espacio dentro de Claude Desktop donde Claude ya sabe quién eres y cómo quieres que funcione. No repites nada.

Sin Cowork

  • Cada chat empieza de cero
  • Repites contexto todo el tiempo
  • No hay memoria entre conversaciones

Con Cowork

  • Claude recuerda tu proyecto completo
  • Instrucciones persistentes en cada chat
  • Contexto siempre disponible

02 crear proyecto

Tu primer proyecto en Cowork

1

Abre Cowork

En Claude Desktop, ve a la sección Cowork en el panel izquierdo.

2

Proyectos > "+"

Haz clic en Projects y luego en el botón "+" para crear uno nuevo.

3

Elige el tipo

Desde cero (en blanco) o desde una carpeta de tu computadora.

Desde cero: Ideal para proyectos nuevos. Tú defines todo manualmente — instrucciones, contexto, archivos.

Desde carpeta: Claude lee la estructura de tu proyecto automáticamente. Ideal si ya tienes código o archivos organizados.

Eso es clave — tu proyecto vive en algún lado de tu computadora y así Claude lo puede ver sin que tú le tengas que explicar nada.

03 instrucciones

Dile a Claude cómo trabajar

Las instrucciones de proyecto moldean el comportamiento de Claude en todas las conversaciones dentro de ese proyecto. Piénsalo como las reglas del juego — cómo quieres que escriba, qué formato usar, qué no debe hacer.

No hagas esto, pero sí haz esto. Esto no lo vuelvas a repetir. Se lo dices una vez y lo aplica siempre.

Ejemplo de instrucciones de proyecto

Copia y adapta estas instrucciones para tu proyecto. Pégalas en la sección "Project Instructions" de tu proyecto en Cowork.

Copiar
Eres mi asistente de marketing para la agencia [nombre].

Formato:
- Responde siempre en español
- Usa bullet points, no párrafos largos
- Incluye métricas cuando sea posible

Reglas:
- Nunca inventes datos — si no sabes, pregunta
- Prioriza acciones concretas sobre teoría
- Cuando propongas copy, dame 3 variantes

No hagas:
- No uses emojis en documentos formales
- No asumas el presupuesto del cliente

Tips para mejores instrucciones

  • Sé específico: "Responde en español" es mejor que "responde en mi idioma"
  • Incluye el "no hagas": Claude respeta restricciones claras
  • Actualiza conforme aprendes: Las instrucciones no son permanentes — ajústalas

04 contexto

Dale a Claude todo lo que necesita

Carpetas locales

Agrega carpetas de tu computadora. Claude puede leer los archivos dentro.

Archivos

Sube documentos directamente al proyecto — PDFs, hojas de cálculo, imágenes.

Páginas web

Pega URLs y Claude extraerá el contenido relevante para tu proyecto.

Cada proyecto es un espacio aislado. Lo que platicas con Claude en un proyecto se queda en ese proyecto, separado de otras conversaciones y otros proyectos. No se te revuelven.

05 tareas programadas

La función más poderosa de Cowork

Aquí es donde todo cambia. Le dices a Claude: "todos los lunes revisa este folder y hazme un resumen de los archivos que están dentro". Le pones un horario, le pones el modelo que va a usar, y Claude lo hace solito.

Tarea programada: resumen semanal

Pega esto en el campo de tarea programada. Ajusta la carpeta, el día y la hora a tu caso.

Copiar
Cada lunes a las 9:00 AM:
1. Revisa la carpeta /Documentos/Reportes/
2. Identifica archivos nuevos o modificados en los últimos 7 días
3. Lee cada archivo y extrae los puntos clave
4. Genera un resumen ejecutivo en /Documentos/Resumenes/resumen-semanal.md
5. Si encuentras algo urgente, ponlo al inicio del resumen marcado como URGENTE

Frecuencia

Elige cuándo se ejecuta — cada hora, diario, semanal, o cron personalizado.

Modelo

Selecciona qué modelo usa la tarea (Haiku para lo simple, Sonnet para lo que requiere razonamiento).

Ejecuciones perdidas

Si tu computadora estaba apagada, Claude revisa los últimos 7 días y ejecuta una vez de recuperación.

Tarea avanzada: monitoreo de competencia

Ejemplo de tarea que combina web scraping con análisis.

Copiar
Cada miércoles a las 8:00 AM:
1. Visita estas 3 páginas web: [URL1], [URL2], [URL3]
2. Extrae los precios actuales de sus productos principales
3. Compara con nuestros precios en /Documentos/precios-actuales.csv
4. Genera un reporte de diferencias en /Documentos/competencia/reporte-semanal.md
5. Si algún competidor bajó más de 10%, márcalo como ALERTA

06 keep awake

Que tu computadora no se duerma

Activar Keep Awake

Claude Desktop → Settings → General → Keep computer awake (actívalo). Esto evita que tu computadora entre en modo de suspensión.

Importante

Las tareas programadas solo se ejecutan mientras tu computadora está encendida y Claude Desktop está abierto. Keep Awake evita la suspensión — pero no enciende tu computadora si la apagas.

Si tu computadora se durmió y se perdió una tarea, Claude revisa los últimos 7 días y ejecuta la más reciente que se haya perdido. Solo ejecuta una — la más reciente.
