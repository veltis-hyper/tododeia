02 investigación

Notebook LM — Tu Investigador Personal

Piénsalo así:

Imagina que tienes una caja mágica. Le avientas artículos, videos, PDFs — lo que sea — y la caja te escupe un resumen listo para que tú solo agarres los puntos buenos y te pongas a crear. Se acabó pasarte horas investigando qué contenido hacer. Le das tu material a Notebook LM y Claude te arma toda la investigación masticada.

Ver en GitHub

Instalar Notebook LM

pip install notebooklm-py
Copiar comando

Cómo usarlo:

  1. Instálalo con el comando de arriba
  2. Dale tus fuentes: artículos, links de YouTube, PDFs, documentos
  3. Notebook LM analiza todo y te da un resumen estructurado con los puntos clave
  4. Usa ese resumen como base para tu siguiente video, post o artículo

Es como tener un asistente que lee 50 páginas por ti y te dice: "Estos son los 5 puntos que importan."

03 imágenes

Banana Cloud — Tu Diseñador de Imágenes

Piénsalo así:

¿Sabes cuando necesitas una imagen para un post y terminas 2 horas en Canva o peleándote con Photoshop? Con Banana Cloud le describes lo que quieres — foto de producto, gráfico para redes, infográfico — y Claude te lo genera en segundos. Sin Canva, sin Photoshop, sin nada.

Ver en GitHub

Clonar Banana Cloud

git clone https://github.com/AgriciDaniel/banana-claude.git && cd banana-claude
Copiar comando

Cómo usarlo:

  1. Clona el repositorio con el comando de arriba
  2. Sigue las instrucciones del README para configurarlo con tu Claude
  3. Descríbele qué imagen necesitas: "foto de producto minimalista", "banner para Instagram"
  4. Banana Cloud genera las imágenes directamente desde Claude

Es como tener un diseñador gráfico que trabaja a la velocidad de la luz — le dices qué quieres y listo.

04 video

Editor Pro Max — Tu Editor de Video

Piénsalo así:

Imagina que tienes un editor de video que nunca se cansa. Le dices "necesito un video con animaciones, transiciones y cortes" y te lo arma completo. No necesitas aprender After Effects ni Premiere. Solo descargas el proyecto, lo abres con Claude y le dices qué video necesitas.

Ver en GitHub

Clonar Editor Pro Max

git clone https://github.com/Hainrixz/editor-pro-max.git && cd editor-pro-max
Copiar comando

Cómo usarlo:

  1. Clona el proyecto con el comando de arriba
  2. Abre la carpeta del proyecto con Claude Code o tu editor favorito
  3. Dile a Claude qué video necesitas: "un video con gráficos animados sobre ventas"
  4. Claude te genera videos completos con animaciones, transiciones y cortes

Es como tener un estudio de producción en tu computadora — solo que el director eres tú y el equipo es Claude.

05 diseño web

Stitch — Tu Diseñador Web

Piénsalo así:

De nada te sirve todo el contenido del mundo si tu página web se ve mal. Con Stitch le describes tu app o tu página web y él te diseña el proyecto completo: colores, tipografía, estructura, todo. Lo que antes tomaba semanas con un diseñador, ahora toma minutos. Y queda listo para pasarlo a código.

Ver en GitHub

Instalar Stitch MCP

npx -y @anthropic-ai/claude-code mcp add stitch -- npx -y stitch-mcp
Copiar comando

Cómo usarlo:

  1. Instala Stitch como servidor MCP con el comando de arriba
  2. Abre Claude Code y descríbele tu proyecto: "una landing page para mi agencia de marketing"
  3. Stitch te genera el diseño completo: paleta de colores, fuentes, layout, componentes
  4. Usa el diseño como guía para que Claude te construya el código

Es como tener un arquitecto digital — le dices cómo quieres tu casa y te da los planos listos para construir.

06 humanizar

Humanízalo — Tu Voz Auténtica

La mejor de todas:

Esta habilidad la creamos para la comunidad. Le avientas cualquier texto escrito por IA y te lo regresa sonando como si tú lo hubieras escrito. Cero frases robóticas, cero guiones raros. Solo tu voz auténtica, hecha por Claude.

Ver en GitHub

Instalar Humanízalo

git clone https://github.com/Hainrixz/humanizalo.git && cd humanizalo
Copiar comando

Cómo usarlo:

  1. Clona el repositorio y sigue las instrucciones del README
  2. Pégale cualquier texto que suene a inteligencia artificial
  3. Humanízalo detecta las frases robóticas y las reescribe en tu estilo natural
  4. El resultado suena como si tú lo hubieras escrito desde cero

Es como tener un traductor de "idioma robot" a "idioma humano" — la IA escribe el borrador y Humanízalo le pone tu personalidad.
