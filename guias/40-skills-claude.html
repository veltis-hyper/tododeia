qué es una skill · 60 segundos

Una skill es un archivo SKILL.md en una carpeta

Una skill de Claude es un archivo de markdown llamado SKILL.md con dos cosas adentro: un frontmatter en YAML que tiene name y description, y un cuerpo con las instrucciones que Claude debe seguir cuando la skill se gatille. La carpeta donde vive el archivo determina si la skill es global (sirve en cualquier conversación) o específica de un proyecto (vive en el repo).

El campo más importante del frontmatter es description: se lee como gatillo. Cuando dice “úsala cuando el usuario quiera redactar un cold email”, Claude la auto-invoca cada vez que tu prompt encaja con ese gatillo. Por eso todas las descripciones de las 40 skills empiezan con “Úsala cuando…” — no es estilo, es contrato con el motor.

Construyes la skill una vez, la usas para siempre. Si te encuentras retipeando el mismo prompt todos los días, ese prompt debería ser una skill. Esta guía te entrega 40 ya hechas y traducidas — abre la siguiente sección y déjalas instaladas en menos de 5 minutos.

Ejemplo mínimo de SKILL.md

---
name: arquitecto-de-hilos
description: Úsala cuando quieras convertir un tema, artículo o idea en un hilo de X.
---

Escribes hilos de X que la gente guarda.

Cuando se invoque:
1. Pide la idea central si no la dieron.
2. Abre con un hook de una línea que pegue.
[…cuerpo de la skill aquí…]

Para más profundidad, la documentación oficial vive en docs.claude.com → Claude Code → Skills y en Agent Skills overview.

instalación · 3 superficies

Cómo dejar una skill instalada en menos de 5 minutos

Hay tres lugares donde una skill puede vivir, y los tres aceptan exactamente el mismo formato de SKILL.md. Elige el que coincida con dónde usas Claude más seguido — o instala la misma skill en los tres si quieres tenerla disponible en cualquier contexto.

  1. 01

    Claude.ai web · Claude Desktop · Cowork

    Settings → Skills → Add Skill

    1. Crea una carpeta en tu disco con el nombre de la skill (ej: arquitecto-de-hilos).
    2. Adentro de esa carpeta pega el archivo SKILL.md de abajo (cópialo desde la card y guárdalo con el nombre exacto SKILL.md).
    3. Comprime la carpeta como .zip — el zip queda con el mismo nombre que la skill.
    4. Entra a claude.ai → Settings → Skills → Add Skill → sube el .zip.
    5. Listo: Claude la auto-invoca cuando el chat dispare el gatillo del campo description.

    Nota: El mismo flow funciona dentro de Claude Desktop y de Claude Cowork — la skill queda disponible en cualquier conversación nueva.

  2. 02

    Claude Code (CLI)

    ~/.claude/skills/<nombre>/SKILL.md

    1. Abre la terminal en tu máquina (Terminal en Mac, PowerShell o WSL en Windows).
    2. Crea la carpeta y el archivo en una sola línea con el comando de abajo.
    3. Pega el SKILL.md de la card en ese archivo y guarda.
    4. En la próxima sesión de Claude Code la skill ya está cargada — no necesitas reiniciar nada más.

    Nota: Las skills globales viven en ~/.claude/skills/. Para una skill específica de un proyecto, usa <repo>/.claude/skills/ y se va al commit junto con el código.

  3. 03

    Equipo · multi-repo

    <repo>/.claude/skills/<nombre>/SKILL.md

    1. En la raíz del repo del equipo crea la carpeta .claude/skills/<nombre>/.
    2. Adentro deja el SKILL.md y haz commit junto con el código del proyecto.
    3. Cuando un compañero clona el repo y abre Claude Code, la skill ya viene incluida — no tiene que instalarla a mano.

    Nota: Es la forma más rápida de que un equipo entero use el mismo prompt. El SKILL.md vive en git, los cambios se revisan en pull request como cualquier otro archivo.

Crear carpeta y archivo SKILL.md (Claude Code · macOS / Linux)

mkdir -p ~/.claude/skills/arquitecto-de-hilos && touch ~/.claude/skills/arquitecto-de-hilos/SKILL.md

Crear carpeta y archivo SKILL.md (Claude Code · Windows PowerShell)

Copiar comando

Listar skills instaladas (Claude Code)

Copiar comando

Comprimir carpeta para subir a Claude.ai (Settings → Skills)

cd ~/.claude/skills && zip -r arquitecto-de-hilos.zip arquitecto-de-hilos/

categoría 01 · 7 skills

Escritura y contenido · 01–07

Las que hacen que una idea cruda se vuelva un hilo, un artículo, un email que recibe respuesta o un guión que retiene. Empieza por la 01 si nunca has instalado una skill — es la más corta y prueba que el flow funciona.

01 · El Arquitecto de Hilos · Principiante

Convierte una idea cruda en un hilo de 7 tweets con hook, cuerpo y CTA suave que la gente guarda.

Copiar
---
name: arquitecto-de-hilos
description: Úsala cuando quieras convertir un tema, artículo o idea en un hilo de X.
---

Escribes hilos de X que la gente guarda.

Cuando se invoque:
1. Pide la idea central si no la dieron.
2. Abre con un hook de una línea que pegue. Sin setup. Sin "¿Alguna vez...".
3. Agrega una línea tipo "Guarda esto" o "Para volver" en el tweet 2.
4. Cuerpo: 5 tweets, una idea por tweet, números específicos, segunda persona.
5. Cierra con una línea final fuerte y un CTA suave de seguimiento.

Reglas: cero em dashes. Cero en dashes. Sin emojis salvo que te los pidan. Cada tweet bajo 280 caracteres.

---

Cuando se invoque:

3. Arma el outline: hook, contraste de setup, 4–6 secciones numeradas, verdad incómoda, línea final.
4. Cada sección lleva una tesis de una línea y 3 bullets.
5. Suma el word count target y el reading time.

Output en markdown con encabezados H2. Sin párrafos introductorios.

32 · El Cazador de Anomalías · Intermedio

Copiar

name: cazador-de-anomalias
description: Úsala cuando el usuario quiera encontrar patrones inusuales en data de serie de tiempo.
---

Cazas anomalías que importan.

Cuando se invoque, pide la data de serie de tiempo y qué cuenta como "inusual".

Después:

2. Marca puntos que excedan 2 sigma. Marca dirección (pico, caída).

cómo usarlas de verdad

La verdad incómoda y los siguientes 30 días

La mayoría va a guardar esta página y nunca va a abrir la carpeta. Un grupo más chico va a copiar 5 skills y empezar mañana. Un grupo todavía más chico va a instalar las 40 y olvidarse de que Claude está haciendo el trabajo. La diferencia entre los tres grupos no es talento. Es si abriste la carpeta.

Claude es el motor. Las skills son el volante. Sin skills estás pisando el acelerador esperando llegar a algún lado bueno. La buena noticia: dejar el volante toma 5 minutos por skill — el comando de la sección de instalación, el copy-paste del SKILL.md, y listo.

Plan de adopción de 30 días

  • Día 1: elige tu pack (sección de arriba). Instala las 5 en una sola sentada usando el método que más usas (Claude.ai web o Claude Code).
  • Días 2–14: usa cada skill al menos 2 veces. Anota cuáles se sienten naturales y cuáles no se gatillan solas — esas necesitan un description más afilado.
  • Días 15–30: tira las 1–2 que no usaste. Cambia por otras del catálogo. Después de 30 días tienes 5 skills ajustadas a tu día — vale más que las 40 sin uso.

Y si llegaste hasta acá pero todavía no abriste la primera carpeta — abre terminal, pega el primer comando de la sección de instalación, copia el SKILL.md de la skill 01, y termina la jugada. La diferencia entre los tres grupos arriba se decide en los próximos 5 minutos.
