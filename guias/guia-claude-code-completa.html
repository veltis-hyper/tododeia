01 · QUÉ ES

Claude Code no es un chat: es un compañero que toca tu compu

La analogía corta · el asesor con manos

Pensá en el Claude de siempre (el chat) como un asesor por teléfono: le contás tu problema y te dicta la solución, pero la tenés que escribir vos. Claude Code es ese mismo asesor pero sentado al lado tuyo en la compu — puede abrir tus archivos, escribir, corregir, probar y dejarte el trabajo hecho. La misma cabeza, pero con manos.

La versión larga · qué cambió y por qué importa

Durante mucho tiempo Claude solo podía hablar. Vos le pegabas un texto, te contestaba con otro texto, y todo lo que te decía lo tenías que copiar y pegar a mano en tu compu. Útil, pero lento. Claude Code rompe esa pared: le das acceso a una carpeta de tu computadora y, con tu permiso, lee lo que hay adentro, crea archivos nuevos, edita los que ya existen y hasta corre los pasos para probar que todo funcione.

Lo importante: vos seguís mandando. Claude no hace nada sin avisarte — cada cambio te lo muestra y vos decidís si va o no. No es que le entregás tu compu y rezás. Es más como tener un asistente muy rápido que te dice 'voy a hacer esto, ¿lo hago?' y vos confirmás. Esa es la diferencia entre un chat que te aconseja y un compañero que te resuelve.

Y la mejor parte para quien recién empieza: no hace falta saber programar para sacarle jugo. Le hablás en español normal — 'ordename estos archivos', 'armame una página simple', 'leé este documento largo y resumime lo importante' — y él se encarga de la parte técnica. Esta guía arranca por la app justamente por eso: vas a empezar tocando botones, no escribiendo comandos raros.

Lee tus archivos

Abre la carpeta que vos le señales y entiende qué hay adentro antes de tocar nada.

Crea y edita

Escribe archivos nuevos y corrige los existentes — siempre mostrándote el cambio antes de aplicarlo.

Corre tareas

Ejecuta los pasos para probar que lo que hizo funciona, sin que vos tengas que saber cómo.

Te explica todo

Cada cosa que hace te la cuenta en español. Si no entendés algo, le preguntás y te lo aclara.

¿Le tenés miedo a la terminal?

Si la palabra 'terminal' te da escalofríos, tranquilo: vas a poder usar Claude Code sin abrir una sola vez la pantalla negra de comandos. La app lo hace casi todo con clics. La terminal la vemos en la sección 08, y para entonces ya no te va a parecer un monstruo.

02 · LA APP

Descargá la app y abrí la sección Claude Code

Este es el camino recomendado para empezar. La app de escritorio de Claude (Mac y Windows) trae Claude Code adentro con una interfaz de botones: no instalás nada técnico, no escribís comandos. Cuatro pasos y estás trabajando. Importante de entrada: Claude Code no está en el plan gratis — necesitás Pro, Max, Team o Enterprise.

01

Descargá e instalá la app de Claude

Andá a la página oficial de descarga y bajá la app de escritorio para tu sistema (Mac o Windows). Se instala como cualquier programa: la abrís, iniciás sesión con tu cuenta de Claude y listo. La app ya trae Claude Code embebido — no hace falta instalar nada aparte.

Descargar Claude (Mac y Windows)

En Windows, la app pide tener Git instalado para trabajar con carpetas locales (lo vemos en la sección 03). En Mac suele venir de fábrica.

02

Abrí la sección Claude Code

Dentro de la app vas a ver la sección de Claude Code (la pestaña 'Code'). Ahí es donde Claude trabaja con tus archivos, distinto del chat normal. Entrás y te recibe una barra lateral para manejar tus sesiones.

03

Empezá una sesión nueva

Una sesión es una conversación de trabajo enfocada en una cosa. Creás una nueva desde la barra lateral. Consejo de oro: una sesión, una meta. No mezcles cinco temas en la misma — abrí una sesión por cada cosa que quieras hacer.

04

Elegí una carpeta

La app te va a pedir que elijas una carpeta con el botón 'Select folder' (elegir carpeta). Esa carpeta es el espacio donde Claude va a trabajar. Si no tenés ninguna todavía, creá una carpeta vacía en tu Escritorio y elegí esa. A partir de ahí, ya le podés pedir cosas en español.

Cada sesión queda apuntando a su propia carpeta, así que podés tener varias trabajando en proyectos distintos a la vez (sección 09 · En paralelo).

Eso es todo para arrancar: descargar, abrir Code, sesión nueva, elegir carpeta. Sin una sola línea de comando. Si querés el detalle por sistema operativo (Mac vs Windows vs Linux) con cada pantalla, mirá la guía dedicada de instalación.

03 · GIT Y NODE

Git y Node: cuándo de verdad los necesitás (y dónde bajarlos)

Acá hay mucho mito. Te dicen 'instalá Git y Node sí o sí' y no siempre es cierto. La verdad honesta depende del camino que elijas. Te lo separo para que no instales cosas que no vas a usar — y te dejo los links oficiales de descarga para cuando sí hacen falta.

Qué necesitás según tu camino

Usás la app de escritorio

No necesitás Node: Claude Code ya viene adentro de la app. En Mac normalmente tampoco tocás nada. En Windows sí conviene tener Git instalado para que la app trabaje bien con tus carpetas locales.

Usás la terminal con el instalador oficial

Tampoco necesitás Node: el instalador nativo trae todo y se actualiza solo. Git sigue siendo recomendable (sobre todo en Windows) para llevar el historial de tus cambios.

Instalás por npm (camino viejo)

Acá sí necesitás Node.js 18 o más nuevo, porque npm es parte de Node. Es el camino que ya no es el recomendado — está si lo preferís, pero el instalador nativo es más simple.

Git — solo si estás en Windows (o querés historial)

Git es la 'memoria' de tus cambios: guarda versiones para que puedas volver atrás si algo se rompe. En Windows la app lo pide para las carpetas locales; en Mac suele venir incluido.

Descargar Git (Mac, Windows, Linux)Git para Windows

O instalá por comando (una sola vez)

winget install --id Git.Git
Copiar comando

Ese comando es para Windows. En Mac, si no lo tenés, corré 'xcode-select --install'. Si preferís el instalador con botones, bajalo de las páginas oficiales de acá abajo — es lo más simple para quien no toca la terminal.

Node.js — solo si vas por el camino npm

Node es el motor que necesita el instalador viejo (npm). Si usás la app o el instalador nativo, podés saltarte esto por completo.

Descargar Node.js (versión LTS)

O instalá por comando (una sola vez)

winget install --id OpenJS.NodeJS.LTS
Copiar comando

En Mac: 'brew install node'. O bajá la versión LTS con botones desde la página oficial de Node. Recordá: esto solo hace falta si elegiste npm.

La regla simple

Regla simple: si recién empezás y vas por la app, no instales Node — no lo vas a usar. Sumá Git solo si estás en Windows. Lo demás es para cuando ya quieras el camino de la terminal por npm, y para ese momento ya vas a saber si lo necesitás.

04 · TU CARPETA

Elegí la carpeta donde Claude va a trabajar

La carpeta es el corazón de cómo funciona Claude Code. Todo lo que Claude lea, cree o cambie pasa dentro de la carpeta que vos elegiste — nada por fuera. Entender esto te da tranquilidad: sabés exactamente dónde está jugando.

Una carpeta = un proyecto

Lo más limpio es una carpeta por proyecto. Tu landing en una, el documento que querés ordenar en otra. Así Claude no mezcla cosas que no tienen que ver.

Todo vive ahí adentro

Claude no anda hurgando el resto de tu compu. Solo ve y toca lo que está dentro de la carpeta que le señalaste. Esa es tu zona segura.

Si no tenés una, creala vacía

No necesitás tener un proyecto armado. Creá una carpeta vacía en el Escritorio, elegila, y pedile a Claude que arranque desde cero. Él te arma la base.

Tu primer prompt · arrancá de cero

Después de elegir una carpeta vacía, pegá esto en la sesión. Es el primer prompt que cualquiera puede mandar sin saber nada técnico — y te muestra cómo Claude explica cada paso.

Copiar
Esta carpeta está vacía y recién empiezo con Claude Code. Antes de hacer nada, contame en español simple qué ves acá adentro y qué cosas podrías ayudarme a construir en esta carpeta.

Después, creá un archivo de notas llamado "ideas.md" y escribí adentro 3 ideas de proyectos chiquitos que podríamos hacer juntos para que yo aprenda a usarte. Explicame qué hiciste paso a paso.

Por qué este primer prompt

Le pedís dos cosas chicas y reversibles (mirar y crear un archivo de notas) en vez de algo grande. Ves cómo Claude trabaja, cómo te explica y cómo te muestra el cambio antes de aplicarlo — todo sin riesgo. Es la mejor forma de perderle el miedo.

05 · QUÉ LE PEDÍS

Qué le podés pedir (aunque no sepas programar)

Claude Code trabaja con los archivos de tu carpeta — y eso sirve para muchísimo más que programar. Acá van ideas concretas para alguien que no escribe código, todas cosas que podés pedir hoy, en español normal.

Ordenar y renombrar archivos

“Tengo 200 fotos con nombres tipo IMG_3920. Ordenámelas en carpetas por mes y renombralas con la fecha y un número.”

Resumir y sacar datos de documentos

“Leé estos 3 PDFs y armame un resumen de una página con los puntos clave y las fechas importantes en una lista.”

Armar una página web simple

“Armame una landing de una sola página para mi negocio, con mis datos de contacto y un botón de WhatsApp. Mostrámela cuando esté.”

Limpiar y armar planillas

“Tengo este archivo de Excel/CSV desordenado. Sacá los duplicados, ordená por fecha y agregame una columna con el total.”

Convertir y juntar textos

“Convertí estos documentos de Word a texto simple y juntalos en un solo archivo, ordenados por tema, con un índice arriba.”

Organizar tus notas

“Tengo notas sueltas en esta carpeta. Agrupámelas por tema, ponele un título a cada una y armame un índice para encontrarlas.”

Ejemplo listo · ordenar una carpeta hecha un desastre

Elegí una carpeta con archivos desordenados (descargas, documentos sueltos) y pegá esto. Es 100% no técnico y te muestra el poder de Claude Code en tareas de todos los días.

Copiar
Esta carpeta está llena de archivos desordenados. Antes de mover nada, hacé esto:

1. Mirá qué hay y agrupalos mentalmente por tipo (imágenes, documentos, planillas, otros).
2. Proponeme un orden de carpetas con nombres claros y mostrámelo ANTES de tocar nada.
3. Cuando yo te dé el OK, movés cada archivo a su carpeta y al final me dejás una nota "orden.md" explicando qué movimos y dónde quedó cada cosa.

Le pedís que te muestre el plan antes de mover nada (vos aprobás primero) y que deje un registro de lo que hizo. Así ves cómo Claude trabaja sobre archivos reales, con red de seguridad, sin escribir una línea de código.

La regla mental

La regla mental: si la tarea vive en archivos de una carpeta y la podés explicar en una frase, es muy probable que Claude Code la pueda hacer. No tiene que ser código — la mayoría de la gente le saca más jugo a tareas de orden, documentos y datos que a programar.

06 · ADENTRO DE LA APP

Cómo se ve trabajar adentro de la app

Cuando le pedís algo, la app no es una caja negra: te muestra todo en paneles que podés acomodar. Lo más importante de entender desde el día uno: la app es una mesa de revisión, no un editor de código. Vos no escribís — revisás y aprobás lo que Claude propone. Con ese chip puesto, todo encaja.

El visor de cambios

Cuando Claude va a modificar algo, te muestra el antes y el después lado a lado, con lo que agrega y lo que saca marcado. Vos aceptás o rechazás. Por defecto la app arranca preguntándote antes de tocar nada.

La barra lateral de sesiones

Lista todas tus sesiones, las activas y las pasadas. Volvés a cualquiera donde la dejaste, las filtrás y corrés varias en paralelo. Es tu tablero de control.

Señalar archivos con @

Escribís @ y el nombre de un archivo para que Claude lo tenga en cuenta en esa instrucción. Así apuntás exacto a lo que querés que mire, sin describirlo con palabras.

Comandos con /

Escribís / (o tocás el botón +) y aparecen comandos y habilidades listas para usar: /goal, /loop y más. Son atajos para tareas comunes, sin memorizar nada.

La vista previa

Claude puede abrir el resultado ahí mismo — una página web andando, un PDF, una imagen — para que veas cómo quedó sin salir de la app ni abrir otro programa.

La terminal integrada (opcional)

Si querés, la app trae una terminal adentro (la abrís con Ctrl+` o desde el menú Views). Es opcional y sirve más para mirar que para tocar — no la necesitás para trabajar.

El chip mental que lo cambia todo

No esperes un editor de código tipo VS Code: la app brilla como lugar para REVISAR el trabajo de Claude. Ver los cambios antes de aceptarlos, previsualizar el resultado y manejar varias sesiones desde un solo lado. Si llegás pensando 'esto es mi editor', te frustrás; si pensás 'esto es mi mesa de revisión', todo cobra sentido.

07 · PERMISOS

Cuándo Claude te pide permiso (y cómo decidís vos)

Claude Code te deja elegir cuánta correa darle. ¿Querés revisar cada cambio antes de que pase? ¿O confiás y lo dejás avanzar más solo? Eso se controla con los modos de permiso. Entenderlos es clave para sentirte en control desde el día uno.

Por defecto — te pregunta

Claude pide tu OK antes de cada cambio importante: editar un archivo, correr un comando. Es el más cuidadoso y el ideal para empezar. Nada pasa sin que vos lo apruebes.

En la app

Es el modo con el que arrancás. Vas viendo cada propuesta y la aprobás o rechazás con un clic.

En la terminal

El modo inicial cuando abrís 'claude'. Te muestra cada acción y esperás tu confirmación.

Aceptar ediciones — más fluido

Claude aplica los cambios de archivos solo, sin frenar a preguntarte por cada uno. Lo usás cuando ya le agarraste confianza a una tarea y no querés estar dando OK todo el tiempo. Igual podés revisar todo después.

En la app

Lo elegís en el selector de modo de la sesión, con un clic.

En la terminal

Lo cambiás con la tecla Shift+Tab, que va rotando entre los modos.

Solo lectura (plan) — mirar sin tocar

Claude puede leer y proponerte un plan, pero no toca ni un archivo. Perfecto para la etapa de pensar: le pedís que analice algo y arme un plan antes de construir, sin riesgo de que cambie nada.

En la app

Lo seleccionás como modo de la sesión cuando querés solo diseñar.

En la terminal

También en el selector con Shift+Tab. Ideal de combinar: primero plan, después construir.

El consejo para empezar: quedate en 'por defecto' las primeras semanas. Revisar cada cambio te enseña cómo trabaja Claude y te da confianza. Cuando ya sepas qué esperar, soltá un poco con 'aceptar ediciones'. Hay un modo aún más automático (auto mode) para dejarlo trabajar solo — esa es otra historia, con su propia guía.

08 · LA TERMINAL

La terminal es lo mismo, sin las rueditas

La terminal es esa pantalla donde escribís comandos en vez de tocar botones. Asusta de lejos, pero hace exactamente lo mismo que la app — corre el mismo Claude Code. La gente avanzada la prefiere porque es más rápida y flexible, pero no es obligatoria. Si la app te alcanza, quedate en la app. Si querés probarla, acá está el camino corto.

09 · EN PARALELO

Varias sesiones a la vez, cada una en lo suyo

Acá está una de las cosas más copadas y menos entendidas. No estás limitado a una sola conversación: podés tener varias sesiones de Claude Code corriendo al mismo tiempo, cada una en su carpeta, construyendo cosas distintas. Una arregla un bug mientras otra escribe una página nueva y otra te investiga algo. Vos vas saltando entre ellas.

Cada sesión, su carpeta y su tarea

En la app, la barra lateral te lista todas tus sesiones. Abrís una nueva, le das una carpeta y una meta. Las sesiones no se pisan entre sí — cada una trabaja sobre su propia copia aislada.

Saltás entre ellas cuando querés

Mientras una sesión piensa o trabaja en algo largo, te pasás a otra y avanzás distinto. No esperás de brazos cruzados a que termine una para empezar la otra.

Empezá con dos, no con diez

Es tentador abrir un montón, pero coordinar muchas a la vez cansa. Arrancá con dos sesiones en paralelo y subí de a poco cuando le agarres la mano.

Arrancá una segunda tarea en paralelo

Abrí una segunda sesión, elegí otra carpeta (o la misma) y pegá algo así para tenerla trabajando mientras vos seguís en la primera.

Copiar
Mientras trabajo otra cosa en paralelo, quiero que vos te encargues de esto solo:

Revisá todos los archivos de esta carpeta y armame un documento "resumen.md" que explique, en español simple, qué hace cada archivo y para qué sirve.

Cuando termines, dejame al final una lista de las 3 cosas que más te llamaron la atención o que crees que podríamos mejorar. Avisame cuando esté listo.

Le das una tarea clara, autocontenida y con un final definido ('avisame cuando esté listo'). Eso es lo ideal para una sesión en paralelo: algo que puede avanzar solo mientras vos estás en otra cosa, y que vos revisás cuando vuelve.

Un detalle importante

Ojo con un detalle: las sesiones en paralelo de la app (la barra lateral) no son lo mismo que 'Agent View'. Agent View es una función de la terminal para lanzar y vigilar agentes que corren en segundo plano. Las dos sirven para trabajar en paralelo, pero son herramientas distintas. Si te interesa la versión terminal, hay guía dedicada.

10 · WEB Y CELULAR

Claude Code desde el navegador y el teléfono

Claude Code no vive solo en tu compu. También corre en el navegador y te deja seguir tus proyectos desde el celular. Tu trabajo te sigue: arrancás en un lado y continuás en otro.

En el navegador

En el navegador (claude.ai/code)

Entrás con tu cuenta y trabajás sin instalar nada. Corre en una máquina en la nube de Anthropic. Para que tenga tus archivos, conectás tu repositorio de GitHub. Necesita plan Pro o superior.

Pensado para tareas que corren solas

La versión web brilla cuando le tirás una tarea y la dejás trabajando en la nube mientras vos hacés otra cosa. No depende de que tu compu esté prendida.

En el celular

Apps oficiales de iOS y Android

Claude tiene app de celular en App Store y Google Play. Desde ahí seguís el estado de tus tareas y aprobás o rechazás acciones, esté tu compu donde esté.

Remote Control · tu sesión en el bolsillo

Es la función que conecta tu celular con una sesión que corre en tu compu. Arrancás algo en la laptop, salís a la calle y seguís dándole instrucciones o aprobando pasos desde el teléfono. Tu código no se sube a ningún lado: el celular solo manda órdenes.

Web y celular son la frutilla del postre, no por donde empezar. Primero dominá la app en tu compu (secciones 02 a 09). Una vez que eso te sale natural, sumar el navegador y el teléfono es cuestión de minutos. La guía hermana cubre el flujo completo web → celular paso a paso.

11 · FUNCIONES NUEVAS

Las funciones nuevas que valen la pena tocar

Claude Code se mueve rápido: cada mes aparecen funciones nuevas. Acá están las que más cambian el día a día de alguien que ya sabe lo básico, explicadas en simple y con un prompt o un comando para probarlas. No hace falta usarlas todas — elegí una, jugá, y volvé por otra. (Las funciones y nombres son a mayo 2026; pueden cambiar.)

/goal · la meta que Claude no suelta

Le fijás una meta concreta y Claude sigue trabajando turno tras turno, solo, hasta cumplirla. Otro modelo revisa si de verdad se logró antes de parar.

Para qué: Para tareas largas que no querés ir empujando de a poco: 'dejá toda la documentación lista', 'arreglá todos los errores de esta lista'. Lo lanzás y volvés cuando terminó.

Probalo

Pegá esto en una sesión para ver la función en acción.

Copiar
/goal Quiero que todos los archivos de esta carpeta tengan un comentario arriba explicando en español qué hace cada uno. La meta se cumple cuando no quede ningún archivo sin ese comentario.

Más a fondo: /goal a fondo

/loop · tareas que se repiten solas

Programás que Claude corra una tarea cada cierto tiempo, sin que vos la dispares cada vez. Como un despertador para trabajo repetitivo.

Para qué: Para rutinas: 'cada mañana revisá esto y armame un resumen', chequeos periódicos, vigilar que algo siga funcionando.

Más a fondo: /loop y tareas programadas

Checkpoints · botón de deshacer

Claude guarda 'fotos' del estado antes de hacer cambios grandes. Si algo no te gustó, volvés a la foto anterior y listo.

Para qué: Para experimentar tranquilo: probás una idea grande sin miedo, porque sabés que podés volver al punto anterior con un paso.

Contexto gigante · entiende proyectos enteros

Claude puede tener en cuenta una cantidad enorme de texto a la vez (del orden de un millón de unidades). En la práctica: agarra un proyecto completo de una sola vez.

Para qué: Para proyectos grandes donde antes tenías que ir mostrándole de a pedacitos. Ahora 'mirá todo y decime' es una instrucción válida.

Agent View · varios agentes en un panel

Un panel en la terminal para lanzar agentes que trabajan en segundo plano y verlos a todos juntos: cuál terminó, cuál espera tu OK, cuál sigue trabajando.

Para qué: Para cuando ya trabajás con varias cosas a la vez y querés un tablero único en vez de saltar entre ventanas.

Más a fondo: Agent View

Remote Control · desde el celular

Conectás tu teléfono a una sesión que corre en tu compu. Seguís dando instrucciones y aprobando pasos desde afuera, sin que tu código salga de tu máquina.

Para qué: Para no quedar atado al escritorio: lanzás algo largo, salís, y lo seguís manejando desde el celular.

Más a fondo: Web y celular

Memoria · que no se olvide de todo

Herramientas que le dan a Claude memoria entre sesiones, para que recuerde decisiones y contexto de tu proyecto sin que se lo repitas cada vez.

Para qué: Para proyectos largos donde te cansás de explicar lo mismo. La memoria carga ese contexto sola al arrancar.

Más a fondo: Memoria para Claude Code

Por dónde arrancar

Consejo: no intentes aprender las seis de golpe. La que más impacto tiene apenas empezás es /goal — dejarlo trabajar solo hacia una meta clara es el momento en que se siente la diferencia con un chat. Probá esa primero.

12 · CONTEXTO

CLAUDE.md: cómo Claude se vuelve experto en TU proyecto

Si hay UN truco que separa a quien sufre con Claude Code de quien vuela, es este: darle contexto de tu proyecto. Claude arranca cada carpeta sin saber nada de vos. El archivo CLAUDE.md es una nota permanente que lee al empezar — quién sos, qué hace el proyecto, cómo te gusta que trabaje. Lo armás una vez y deja de preguntarte lo mismo.

Qué es

Un archivo de texto llamado CLAUDE.md que vive en tu carpeta. Claude lo lee solo al arrancar cada sesión. Ahí ponés las reglas e info de tu proyecto.

Qué poner adentro

Qué hace el proyecto, qué herramientas usás, cómo querés que te hable, qué cosas NO querés que haga. Cuanto más claro, menos te malinterpreta.

Cómo se arma sin esfuerzo

No lo escribís a mano: Claude lo genera por vos. En la terminal hay un comando, /init, que recorre tu proyecto y arma un primer CLAUDE.md. En la app se lo pedís directo.

Que Claude arme tu CLAUDE.md

Pegá esto en una sesión que apunte a tu proyecto. Claude lo recorre y te arma la nota de contexto inicial, que después ajustás.

Copiar
Mirá toda esta carpeta y armame un archivo CLAUDE.md que sirva de contexto para cualquier sesión futura. Incluí, en español simple:

1. Qué hace este proyecto, en 2 o 3 líneas.
2. Qué herramientas o tecnologías usa.
3. Cómo prefiero que me hables (en español, voseo, explicando cada paso).
4. Cosas importantes que deberías saber antes de tocar nada.

Cuando termines, mostrame qué escribiste y explicame por qué pusiste cada parte.

Lo más importante de la parte avanzada

El CLAUDE.md es lo que convierte a Claude de 'asistente genérico' en 'asistente que conoce tu proyecto'. Es la diferencia entre repetir tu contexto en cada chat y que ya lo sepa. Si te llevás una sola cosa de la parte avanzada, llevate esta.

13 · SIGUIENTE NIVEL

Skills, conectores (MCP) y subagentes

Cuando ya te sentís cómodo, estas tres piezas son las que llevan Claude Code de 'útil' a 'parece magia'. No hace falta usarlas para empezar — pero conviene saber que existen, para saber qué buscar el día que las necesités. Te las cuento cortas; cada una tiene su guía dedicada.

Skills · recetas que Claude aprende

Una skill es una habilidad guardada: un conjunto de instrucciones que Claude carga cuando hace falta. Como darle un manual que ya sabe seguir.

Cuándo: Cuando hacés una misma tarea seguido y querés que Claude la haga siempre igual de bien, sin re-explicarla cada vez.

Conectores (MCP) · enchufes a otras apps

MCP es la forma en que Claude se conecta con apps y servicios externos — tu correo, tu calendario, una base de datos, GitHub. Es como un cable que le da acceso a otra herramienta.

Cuándo: Cuando querés que Claude no solo trabaje con tus archivos, sino que también lea o escriba en otras apps que ya usás.

Subagentes · ayudantes especializados

Claude puede delegar partes del trabajo a 'subagentes': mini-asistentes con una especialidad (uno revisa seguridad, otro corre pruebas) que trabajan en paralelo y le reportan.

Cuándo: Cuando una tarea es grande y tiene partes distintas. El agente principal coordina y los subagentes ejecutan cada parte.

Si estos tres nombres te suenan a chino, no te preocupes — es justo lo que cubre la guía Anatomía de Claude, que explica cada pieza (proyecto, skill, MCP, agente, plugin) a nivel niño de 5 años antes de saltar a la práctica.

14 · CUÁNDO NO

Para quién todavía no es esto (y está bien)

Claude Code es buenísimo, pero no es para todo ni para todos hoy. Estos son los casos honestos donde, por ahora, mejor frená o usá otra cosa. Decírtelo te ahorra frustración.

Solo querés hacer una pregunta rápida

Si lo único que necesitás es preguntar algo y que te contesten — sin tocar archivos ni armar nada — el chat normal de Claude te alcanza y es más directo. Claude Code brilla cuando hay una carpeta y un trabajo que hacer, no para dudas sueltas.

No querés que un programa toque tus archivos

Claude Code, por diseño, lee y modifica archivos de la carpeta que le des. Si la idea de que un asistente cree o cambie cosas en tu compu te incomoda, es totalmente válido — usá el chat web y copiá a mano lo que quieras aplicar.

No tenés un plan pago de Claude

Claude Code no está en el plan gratis. Necesitás Pro, Max, Team o Enterprise. Si todavía estás probando si Claude te sirve, empezá por el chat gratis y, cuando veas que lo usás seguido, subís de plan.

No tenés ni 20 minutos para el setup inicial

La primera vez hay que descargar la app, elegir una carpeta y agarrarle la mano. No es difícil, pero requiere sentarse un rato sin apuro. Si andás corriendo, dejalo para un momento tranquilo — la mala primera impresión casi siempre es por hacerlo apurado.

Guía de la comunidad

Esta guía nace de ver, una y otra vez, que lo único que frena a la gente con Claude Code es el miedo a la terminal — un miedo que se cae apenas elegís tu primera carpeta. Se publica como parte de la bóveda de tododeia, una colección libre de recursos para quienes construyen con Claude todos los días. Es la puerta de entrada: empezás acá y profundizás en las guías hermanas cuando lo necesités.

Cierre personal · el muro de humo

“El miedo a la terminal es el muro que frena a casi todos — y es un muro de humo. Claude Code arranca en una app con botones, te explica cada paso en español y no hace nada sin tu permiso. El día que elegís tu primera carpeta y le ves crear el primer archivo, se te cae la ficha: no necesitabas ser programador, necesitabas empezar. Dale una tarde tranquila. Después no vas a querer trabajar de otra forma.”
