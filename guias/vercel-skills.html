Vercel Skills

aprende a descubrir e instalar skills para Claude Code usando skills.sh y el skill find-skills. no necesitas experiencia previa — esta guía empieza desde cero.

Qué es un skill

un skill es un paquete de instrucciones que le dice a Claude Code cómo hacer algo específico. piensa en ellos como superpoderes que le agregas a tu agente: diseño frontend, deploy, testing, y más.

cuando instalas un skill, Claude Code lo lee automáticamente y lo usa cuando es relevante. no tienes que memorizar comandos ni configurar nada extra.

Qué es skills.sh

skills.sh es un directorio abierto donde puedes buscar skills disponibles para Claude Code. funciona como una tienda de habilidades: buscas lo que necesitas e instalas con un solo comando.

abrir skills.sh

Paso 1: Instala find-skills

find-skills es un skill que le da a Claude Code la capacidad de buscar e instalar otros skills por ti. es lo primero que debes instalar.

Instalar find-skills

npx skills add https://github.com/vercel-labs/skills --skill find-skills
Copiar comando

Paso 2: Usa find-skills

una vez instalado, puedes pedirle a Claude Code que busque skills por tema o que instale lo que encuentre.

Buscar por tema

escribe en Claude Code algo como "busca skills de frontend" o "encuentra skills para testing". find-skills buscará en el directorio y te mostrará opciones.

Instalar lo que encuentres

cuando veas un skill que te interesa, dile a Claude Code "instala ese skill" y lo configura automáticamente.

Paso 3: Pídele a Claude Code

no necesitas memorizar comandos. una vez que tienes find-skills instalado, puedes hablarle en lenguaje natural.

"busca skills para hacer deploy en vercel"
"instala un skill de diseño frontend"
"qué skills hay para bases de datos?"
"muéstrame skills de testing y calidad"

Para quién es esta guía

si estás empezando con Claude Code y quieres que haga más cosas sin configurar nada a mano, los skills son tu mejor opción. esta guía te enseña el flujo más simple para empezar.
