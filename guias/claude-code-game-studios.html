Explicado fácil

Imagínate que quieres hacer un videojuego pero no sabes nada de programación, ni de arte, ni de sonido.

Este repo le da a Claude Code un equipo entero: 49 personitas virtuales que trabajan juntas como si fueran un estudio de verdad. Cada una sabe algo distinto — hay quien piensa la idea, quien diseña las reglas, quien programa, quien dibuja, quien pone la música y quien prueba que todo funcione.

Tú le dices qué juego quieres. Claude te pregunta cositas, te da opciones, y entre todos te lo construyen. Nunca escribe nada sin que tú digas que sí.

01 equipo

Cómo funciona el equipo

Directores

Cuidan la visión

Se aseguran de que tu juego tenga alma y no se desvíe. Toman decisiones grandes: de qué trata, qué se siente jugarlo, para quién es.

Líderes de área

Mandan cada disciplina

Uno manda en game design, otro en código, otro en arte, otro en sonido, otro en QA. Cada uno coordina a sus especialistas.

49 especialistas

Los que le entran

Idea, game design, programación, arte, animación, sonido, UI, QA, release. Cada uno es bueno en una sola cosa — por eso queda bien hecho.

Regla de oro: cada agente te pregunta primero. Te da 2 a 4 opciones claras, tú decides, y nada se escribe sin tu visto bueno. Es tu estudio — Claude solo pone las manos.

02 comandos

72 comandos — los que más vas a usar

Cada comando activa a los especialistas correctos. Solo escribes la diagonal y Claude hace el resto.

/brainstorm

Te avienta ideas de juegos y te ayuda a escoger una.

/design-system

Arma las mecánicas: cómo se juega, reglas y loop central.

/dev-story

Programa una feature completa paso a paso.

/qa-plan

Revisa bugs y arma un plan de pruebas antes de publicar.

/art-direction

Define la dirección visual: estilo, paleta y referencias.

/sound-design

Crea el plan de música y efectos para tu juego.

/playtest

Simula sesiones de prueba con jugadores imaginarios.

/release-plan

Te guía para publicar en Steam, itch.io o móvil.

Y así hasta 72 — uno para cada momento del desarrollo. No te los tienes que aprender de memoria: Claude te sugiere cuál usar cuando lo necesites.

03 motor

Escoge tu motor

El motor es el programa con el que se hace el juego. Escoges uno y Claude solo te pone a los especialistas que saben de ese — no te revuelve todo.

Gratis · Open source

Godot

El más fácil para empezar. Perfecto si es tu primer juego o quieres publicar en móvil y web sin complicarte.

Industria · C#

Unity

El que más estudios usan en el mundo. Ideal si quieres vender tu juego o tener la mayor cantidad de tutoriales.

AAA · Blueprints

Unreal

Gráficos de alto nivel. Para juegos 3D ambiciosos, shooters o experiencias visuales potentes.

04 caminos

Tres caminos: hobby, vender o proyecto en serio

Hobby

Haz el juego que siempre has querido, sin presión. Publícalo gratis en itch.io y juégalo con amigos.

Venderlo

Lánzalo en Steam, App Store o Play Store. El equipo incluye especialistas de monetización y release.

Proyecto en serio

Arma un estudio indie, demuestra una idea para inversión, o usa el repo como base de tu portafolio profesional.

05 instalación

Instalación — opción fácil (recomendada)

No necesitas clonar nada a mano. Abre Claude Code en la carpeta donde quieres tu juego, pega este prompt y él se encarga de todo.

Prompt todo-en-uno

Pega esto en Claude Code. Descarga el repo, lo instala y te deja listo para empezar.

Copiar
Instala el repo https://github.com/Donchitos/Claude-Code-Game-Studios en esta carpeta.

Pasos:
1. Clónalo con git clone.
2. Lee su README con Read o WebFetch para entender la estructura.
3. Sigue los pasos de instalación que indica el propio repo (copiar /agents, /commands y config a la raíz del proyecto según corresponda).
4. Cuando termines, resúmeme en español qué agentes y comandos quedaron disponibles y cómo empiezo.

Importante:
- Si el repo pide escoger motor (Godot, Unity o Unreal), pregúntame primero cuál quiero.
- No corras nada destructivo sin confirmarme.
- Pregúntame antes de escribir código del juego — primero quiero ver el equipo listo.

07 empieza

Tu primer juego en 5 pasos

  1. Pega el prompt de instalación en Claude Code y deja que termine.
  2. Escoge motor cuando te pregunte — Godot si es tu primera vez (es gratis y fácil).
  3. Corre /brainstorm y dile en una línea qué juego quieres hacer.
  4. Corre /design-system para definir cómo se juega.
  5. Corre /dev-story para la primera feature y /qa-plan para probarla.
