01Piloto automático para Claude Codev5.1.0

06 n8n + claude · las 3 capas

La confusión #1 del ecosistema · despejada

Acá viene la confusión #1 del ecosistema · 'n8n + Claude' significa 3 cosas distintas y la gente las mezcla todo el tiempo. Estas son las 3 capas que tenés que distinguir antes de elegir cuál instalar.

Capa 01n8n oficial

Anthropic node

Claude como modelo dentro de n8n

Qué es

El nodo built-in de n8n para llamar a la API de Anthropic desde un workflow. Tiene un subnodo 'Anthropic Chat Model' que se conecta a los AI Agents de n8n. Soporta análisis de documentos · imágenes · generación y mejora de prompts.

Caso de uso

Querés que un workflow de n8n use Claude como cerebro · por ejemplo · email entra → Claude lo clasifica → n8n responde. Acá Claude es UNA pieza dentro del flujo · no quien lo controla.

Instalación

Nada que instalar · viene incluido en n8n. Solo agregás el nodo 'Anthropic' o 'Anthropic Chat Model' en el editor y le pegás tu API key.

Documentación oficial
Capa 02n8n oficial

MCP Server Trigger

n8n actúa como MCP server para Claude

Qué es

Un nodo core de n8n (sección LangChain) que convierte a tu instancia de n8n EN un MCP server. Te genera una MCP URL + Bearer Token · conectás tus workflows como tools · y Claude (Desktop o Code) los consume como si fueran herramientas propias. Disponible desde n8n Cloud v1.88+.

Caso de uso

Querés que Claude pueda llamar a tus workflows · por ejemplo · le pedís 'mandá este resumen al canal de Slack del equipo' y Claude dispara el workflow correspondiente. Acá Claude controla · n8n ejecuta.

Instalación

En n8n agregás el nodo 'MCP Server Trigger' → conectás tus workflows como tools → copiás la URL + Bearer Token. En Claude Desktop config sumás un gateway con npx mcp-remote y el header Authorization Bearer.

Documentación oficial
Capa 03community

n8n-mcp (czlonkowski)

Claude diseña y crea workflows de n8n

Qué es

Un MCP server community que le da a Claude conocimiento profundo de n8n (1,851 nodos · 2,352 templates · validación) para que diseñe workflows desde cero o los cree directamente en tu instancia vía API. Es la herramienta #5 de esta guía.

Caso de uso

Querés decirle a Claude 'diseñame un workflow que cada lunes revise X y me mande Y por email' · y que él arme el JSON completo o lo cree directo en tu n8n. Acá Claude es arquitecto · n8n es la plataforma.

Instalación

claude mcp add n8n-mcp -- npx n8n-mcp con env vars MCP_MODE=stdio · N8N_API_URL · N8N_API_KEY. O usás el dashboard hosteado (dashboard.n8n-mcp.com) con tier free de 100 tool calls/día.

Documentación oficial

Cómo elegir cuál instalar

Si tu workflow ya está armado y solo querés que Claude sea uno de los pasos · usá el Anthropic node (capa 01). Si querés que Claude ejecute tus workflows como tools desde una conversación · usá el MCP Server Trigger oficial (capa 02). Si querés que Claude DISEÑE los workflows por vos · usá n8n-mcp de czlonkowski (capa 03). Las tres pueden convivir en el mismo setup · resuelven necesidades distintas.

07 marketplace oficial

/plugin install · el camino moderno

En enero 2026 Anthropic abrió el marketplace oficial de plugins de Claude Code. Cambia las reglas del juego · ya no tenés que hacer git clone · npx · ni copiar configs a mano. Un solo comando instala skills · subagentes · MCP servers · hooks y comandos slash empaquetados.

Paso 01

Abrís Claude Code

Desde la terminal · en cualquier proyecto. No necesitás un marketplace web · todo se maneja por comandos slash dentro del CLI.

Paso 02

Ejecutás /plugin

El comando abre el browser de plugins integrado · te muestra los disponibles · sus dependencias y qué eventos hookeán. En mayo 2026 hay más de 15,000 plugins indexados.

Paso 03

Instalás con /plugin install nombre@source

Por ejemplo · /plugin install superpowers@claude-plugins-official baja Superpowers desde el marketplace oficial de Anthropic. Para fuentes terceras · usás --plugin-url. Sin configs manuales · sin envidiarle nada a un app store.
