Skill Seekers + Obsidian

Aprende a convertir cualquier fuente de información en contexto para Claude — repos de GitHub, PDFs, videos, wikis, Notion — organizarlo en tu cuaderno privado de Obsidian, y dárselo listo a Claude para que trabaje con información precisa.

Las tres herramientas

Piensa en esto como una línea de trabajo: primero recopilas la información, luego la organizas, y finalmente se la das a Claude para que trabaje con ella.

Skill Seekers

El recopilador — extrae información de cualquier fuente y la organiza para Claude

Obsidian

El cuaderno inteligente — guarda tus notas conectadas de forma privada en tu computadora

obsidian-skills

Las manos de Claude — le permite leer y escribir notas en tu cuaderno de Obsidian

02 skill seekers

Skill Seekers — El recopilador de contexto

Qué es esto (explicación simple)

Imagina que tienes un asistente que puede ir a cualquier lugar a recopilar información — un repositorio de GitHub, un video de YouTube, un PDF, una wiki de empresa — y te la regresa organizada y lista para que Claude la entienda. Eso es Skill Seekers. Lo que antes tomaba horas de copia y pega, ahora son tres comandos.

Fuentes que puede procesar

  • Sitios web y documentación técnica
  • Repositorios de GitHub completos
  • PDFs (incluso los escaneados, con OCR)
  • Videos de YouTube y archivos de video locales
  • Jupyter Notebooks, Word y PowerPoint
  • Notion, Confluence, Slack, Discord
  • RSS feeds, man pages y APIs

Paso 1: Instalar Skill Seekers

Ve primero al repositorio oficial en GitHub — ahí están las instrucciones completas de instalación para Mac, Windows y Linux (incluyendo cómo instalar Python si no lo tienes): github.com/yusufkaraaslan/Skill_Seekers

Si ya tienes Python instalado, el comando de instalación rápida es:

Instalar Skill Seekers (requiere Python)

pip install skill-seekers
Copiar comando

Paso 2: Los 3 comandos para usarlo

Una vez instalado, con estos tres comandos conviertes cualquier fuente en contexto para Claude:

Extraer información de cualquier fuente

skill-seekers create [URL o ruta del archivo]
Copiar comando

Mejorar el contexto extraído con IA

skill-seekers enhance skill-seekers-output/
Copiar comando

Empaquetar para Claude

skill-seekers package skill-seekers-output/ --target claude
Copiar comando

Qué produce el comando package

Genera un archivo estructurado específicamente para la ventana de contexto de Claude. Puedes pegarlo directamente en una conversación o cargarlo como contexto en Claude Code. El flag --target claude es lo que marca la diferencia — sin él, el output es genérico y Claude lo procesa con menos eficiencia.

03 obsidian

Obsidian — Tu cuaderno inteligente y privado

Qué es Obsidian (explicación simple)

Imagina un cuaderno donde todas tus notas están conectadas entre sí como una red. Escribes una nota sobre "marketing" y la conectas con "redes sociales" y "clientes". Obsidian te muestra un mapa visual de cómo se relacionan todas tus ideas. Y lo mejor: todo se guarda en tu computadora, no en la nube de nadie.

Dónde descargarlo

Es gratis para uso personal. Descárgalo directamente en obsidian.md. Disponible para Mac, Windows, Linux, iOS y Android.

Cómo funciona por dentro

  • Vault — tu carpeta principal, como el cuaderno completo
  • Notas — archivos de texto simples en formato Markdown (.md)
  • Wikilinks — conectas notas escribiendo [[nombre de nota]]
  • Mapa del conocimiento — vista visual de cómo se conectan todas tus notas

Todo se guarda en tu computadora

A diferencia de Notion o Google Docs, Obsidian guarda todo como archivos de texto plano en tu disco duro. Sin nubes obligatorias. Sin suscripciones para usar las funciones básicas. Tus notas son tuyas.

04 obsidian-skills

obsidian-skills — Las manos de Claude en tu cuaderno

Qué es esto (explicación simple)

obsidian-skills es un conjunto de habilidades para Claude Code creado por kepano (el creador del tema Minimal de Obsidian). Le enseña a Claude a escribir en formato Obsidian — con wikilinks, bases de datos, canvas y todos los elementos especiales que Obsidian entiende. Sin esto, Claude escribiría Markdown genérico que no se ve bien en Obsidian.

Habilidades incluidas

  • obsidian-markdown — escribe notas con sintaxis nativa de Obsidian
  • obsidian-bases — crea y edita bases de datos y filtros
  • json-canvas — genera diagramas visuales y mapas de conexiones
  • obsidian-cli — ejecuta operaciones de Obsidian desde la terminal
  • defuddle — extrae contenido limpio de páginas web en formato Markdown

Opción A — claude install-skill (más fácil)

Desde tu terminal, con Claude Code instalado:

Instalar obsidian-skills

claude install-skill https://github.com/kepano/obsidian-skills
Copiar comando

Opción B — Manual (directo en tu vault de Obsidian)

Descarga el repositorio de github.com/kepano/obsidian-skills y copia todos los archivos dentro de la carpeta /.claude dentro de tu vault de Obsidian. Así Claude Code carga las habilidades automáticamente cuando abres Claude Code desde esa carpeta.

05 todo junto

El flujo completo: Skill Seekers → Obsidian → Claude

Ahora que tienes las tres herramientas, úsalas como un pipeline. Cada una hace su parte:

1. Recopila

Skill Seekers extrae info de cualquier fuente y la empaqueta para Claude

2. Organiza

Obsidian guarda y conecta las notas en tu base de conocimiento local

3. Trabaja

Claude lee el contexto organizado y ejecuta tareas con información precisa

Cómo usar estos prompts

Estos prompts van dentro de Claude Code (en tu terminal), no en el chat de Claude.ai. Para que Claude pueda crear las notas en tu vault de Obsidian, abre Claude Code desde la carpeta de tu vault: cd tu-vault-de-obsidian && claude. Claude Code ejecutará los comandos de Skill Seekers en tu terminal y creará las notas directamente en tu vault.

Prompt 1: Analiza un repositorio completo

Convierte cualquier repo de GitHub en notas organizadas en tu vault de Obsidian.

Copiar
Usa Skill Seekers para extraer y empaquetar el repositorio de GitHub [URL del repo]:

skill-seekers create [URL del repo]
skill-seekers enhance skill-seekers-output/
skill-seekers package skill-seekers-output/ --target claude

Con el contexto empaquetado, crea notas en mi vault de Obsidian que expliquen:
1. Qué hace este proyecto y para qué sirve
2. Cómo está organizado el código (estructura de carpetas)
3. Los conceptos clave que debo entender
4. Cómo empezar a usarlo paso a paso

Usa formato Obsidian con wikilinks entre las notas para conectar los conceptos relacionados.

Prompt 2: Convierte un video de YouTube en notas

Extrae el conocimiento de cualquier video y guárdalo estructurado en Obsidian.

Copiar
Usa Skill Seekers para extraer el contenido de este video de YouTube: [URL del video]

skill-seekers create [URL del video]
skill-seekers enhance skill-seekers-output/
skill-seekers package skill-seekers-output/ --target claude

Con la transcripción y contexto, crea una nota en mi vault de Obsidian con:
- Resumen de los puntos principales (máximo 5 bullets)
- Conceptos clave con sus definiciones
- Pasos accionables que puedo aplicar hoy
- Links a notas relacionadas que ya tenga en mi vault

Título de la nota: [título descriptivo del video]

Prompt 3: Investiga un tema desde múltiples fuentes

Combina varias fuentes en una base de conocimiento coherente en Obsidian.

Copiar
Voy a investigar el tema de [tu tema]. Usa Skill Seekers para extraer información de estas fuentes:

skill-seekers create [URL 1 - artículo o documentación]
skill-seekers create [URL 2 - repo de GitHub relacionado]
skill-seekers create [URL 3 - PDF o video]
skill-seekers enhance skill-seekers-output/
skill-seekers package skill-seekers-output/ --target claude

Con toda la información extraída, crea un conjunto de notas en mi vault de Obsidian:
1. Una nota principal con el resumen de todo lo que aprendiste
2. Notas separadas para cada concepto importante
3. Una nota de "Preguntas sin responder" con lo que falta investigar
4. Conecta todas las notas con wikilinks

Dame un índice al final con los títulos de todas las notas creadas.

06 buenas prácticas

Tips para tu base de conocimiento

Organiza por proyectos

Crea una carpeta por proyecto dentro de tu vault. Así cuando trabajas en un proyecto con Claude Code, todas las notas relevantes están en un solo lugar.

Usa enhance antes de package

El comando enhance mejora la calidad del contexto extraído con IA antes de pasárselo a Claude. Siempre hazlo — la diferencia en calidad es notable.

--target claude hace la diferencia

Este flag estructura la salida específicamente para la ventana de contexto de Claude. Sin él, el output es genérico y Claude lo procesa con menos eficiencia.

Actualiza el contexto regularmente

Si una fuente cambia (documentación actualizada, nuevo video, repo con cambios), vuelve a correr skill-seekers create para tener el contexto más reciente.
