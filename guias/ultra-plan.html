01 qué es esto

Un Segundo Cerebro Que Planea Por Ti

Imagina esto:

Le dices a Claude qué quieres construir y él se va a la nube a armar el plan. Mientras tanto, tu terminal queda libre para que sigas trabajando en otra cosa. Cuando termina, te avisa. Tú abres el plan en tu navegador y lo revisas sección por sección.

Si algo no te gusta, dejas un comentario ahí mismo y Claude lo arregla. Puedes iterar las veces que quieras hasta que el plan quede como lo necesitas. Y cuando ya esté perfecto, tú decides: lo ejecuta en la nube y te abre un Pull Request automático, o lo manda de vuelta a tu terminal para que tú lo corras localmente.

Antes de empezar, checa esto:

  • Claude Code versión 2.1.91 o superior
  • Cuenta de Claude Code on the web activa
  • Un repositorio de GitHub conectado
  • No está disponible en Amazon Bedrock, Google Vertex AI ni Microsoft Foundry
  • Está en research preview — el comportamiento puede cambiar

Se acabó gastar tu cuenta de Claude en algo que al final no era lo que querías.

02 cómo usarlo

Un Comando y a Revisar

Abre Claude Code en tu terminal y escribe /ultraplan seguido de lo que quieres hacer. Así de simple.

Lanzar Ultra Plan desde la terminal

/ultraplan migrar la autenticación de sesiones a JWT manteniendo los usuarios actuales
Copiar comando
1

En tu terminal, escribe /ultraplan seguido de lo que quieres construir. También puedes incluir la palabra ultraplan dentro de cualquier prompt normal.

2

Claude abre una sesión en la nube y empieza a planear. Tu terminal queda libre — puedes seguir trabajando mientras él investiga el código.

3

Cuando veas ◆ ultraplan ready en el indicador, abre el enlace en tu navegador para revisar el plan.

4

Selecciona cualquier sección del plan, deja un comentario o una reacción, y pídele cambios hasta que quede perfecto.

5

Cuando esté listo, elige: ejecutar en la nube (abre un Pull Request automático) o mandarlo de vuelta a tu terminal para implementarlo localmente.

Listo. Revisas antes de construir.

Es como revisar los planos de tu casa antes de empezar la obra. Si hay que mover una pared, la mueves en el papel — no tirando la que ya construiste.

03 cuándo usarlo

Copia un Prompt y Pruébalo

Migrar autenticación

Para cambios grandes en código crítico — Ultra Plan brilla cuando necesitas revisar cada paso antes de tocar nada.

Copiar
/ultraplan migrar la autenticación de sesiones a JWT manteniendo los usuarios existentes, sin romper las sesiones activas y actualizando los tests

Rediseñar dashboard

Para refactors de UI donde quieres ver el plan antes de que Claude cambie 20 archivos.

Copiar
/ultraplan rediseñar el dashboard con Tailwind v4 y dark mode, reutilizando los componentes actuales de shadcn y manteniendo las rutas del App Router

Nueva feature completa

Para features grandes con muchas piezas — Stripe, webhooks, base de datos, UI. Mejor revisar primero.

Copiar
/ultraplan añadir un sistema de suscripciones con Stripe: pricing page, checkout, webhooks para renovaciones y panel de usuario para gestionar su plan

Úsalo cuando no quieras repetir trabajo

Cualquier cambio grande, crítico o con muchas piezas, mándalo por Ultra Plan primero. Revisas, comentas, ajustas — y cuando ya te late el plan, lo ejecutas. Así no gastas tu cuenta construyendo algo que al final no era lo que querías.
