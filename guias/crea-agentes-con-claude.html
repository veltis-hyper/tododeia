01 concepto

¿Qué es un agente?

Un agente es un Claude con un trabajo específico. Tiene una tarea definida, acceso a las herramientas que necesita y puede trabajar de forma autónoma.

Piénsalo como contratar a un empleado especializado: le dices qué hacer, le das acceso a las herramientas que necesita y trabaja solo.

Agente de Code Review

Revisa cada PR que abres, detecta bugs, sugiere mejoras y verifica que el código siga los estándares del proyecto.

Agente de Email

Organiza tu bandeja de entrada, clasifica correos por prioridad y redacta borradores de respuesta automáticamente.

Agente de Monitoreo

Vigila tu sitio web, detecta errores o caídas y te notifica con un reporte de lo que encontró.

03 descubrimiento

¿No sabes qué agente crear?

No necesitas llegar con una idea clara. Si no sabes qué agente te conviene, deja que Claude te entreviste.

Claude te hace preguntas sobre tu día a día, identifica las tareas repetitivas que más tiempo te quitan y te sugiere agentes específicos para automatizarlas.

Prompt de descubrimiento

Claude te entrevista para descubrir qué agentes necesitas.

Copiar
Hazme preguntas sobre mi día a día, mi trabajo y mis tareas repetitivas.
Basándote en mis respuestas, sugiere 3 agentes que podrían automatizar las tareas más tediosas.

Para cada agente, incluye:
- Qué haría exactamente
- Qué herramientas necesitaría
- Cuánto tiempo me ahorraría por semana

No necesitas saber programar ni tener una idea clara.

Claude te guía desde cero. Solo necesitas describir tu trabajo y Claude identifica las oportunidades de automatización. El agente más útil muchas veces es uno que no sabías que necesitabas.

04 herramientas

Cómo Claude conecta herramientas externas

Cuando tu agente necesita interactuar con sistemas externos — Gmail, GitHub, bases de datos, APIs — Claude usa MCP (Model Context Protocol) para conectarse.

MCP es el puente entre Claude y las herramientas externas. Claude no solo construye el código del agente — te dice exactamente qué MCP servers instalar y cómo configurarlos.

Gmail MCP

Para agentes de email — leer, clasificar, responder y organizar tu bandeja de entrada.

GitHub MCP

Para agentes de code review — leer PRs, dejar comentarios, revisar issues y gestionar repos.

Browser MCP

Para agentes de automatización web — navegar páginas, extraer datos y llenar formularios.

Ejemplo: instalar un MCP server

claude mcp add gmail-mcp -- npx -y @anthropic/gmail-mcp
Copiar comando

No necesitas instalar MCPs manualmente. Cuando describes tu agente en Plan Mode, Claude detecta qué herramientas externas necesita y incluye la instalación de MCPs en el plan. Tú solo apruebas y Claude lo configura todo.

05 programar

Potencia tu agente con /loop y schedules

Una vez que tu agente existe, puedes programarlo para que se ejecute automáticamente. Esto convierte un agente de una sola vez en un trabajador persistente.

/loop ejecuta tu agente en intervalos regulares — cada 5 minutos, cada hora, diario. También puedes usar el Desktop scheduler para programarlo visualmente sin tocar la terminal.

Revisar PRs cada 2 horas

/loop 2h revisa los PRs abiertos y deja comentarios de code review

Organizar email cada mañana
