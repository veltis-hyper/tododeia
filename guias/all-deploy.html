01 concepto

¿Qué es All Deploy?

Hiciste tu proyecto con Claude Code pero quedó parado en tu carpeta local. Sin dominio, sin nadie que lo pueda ver, sin forma de enseñárselo a un cliente. El problema no era construirlo — era subirlo.

All Deploy es la habilidad que cierra ese hueco. La instalas en Claude Code, le dices “sube esto” y ella se encarga: detecta qué tipo de proyecto hiciste, elige la plataforma correcta, corre una revisión de seguridad previa, te deja ver un preview y te entrega el comando de rollback listo.

Es la tercera habilidad gratis de un combo pensado para ir de idea a en vivo sin depender de nadie.

02 instalación

Cómo instalarlo

Antes de empezar — necesitas Claude Code

Esta habilidad solo funciona dentro de Claude Code, la herramienta oficial que Anthropic incluye en la app de Claude. Si todavía no la tienes:

  1. Descarga la app de Claude desde claude.ai/download.
  2. Abre Claude Code desde la app (está incluido con cualquier plan de Claude).
  3. Recién ahí corre el prompt o el comando de abajo.

El comando /all-deploy NO funciona en la terminal suelta ni en otros editores — tiene que ser en Claude Code.

Al igual que el resto del combo, All Deploy se instala clonando el repositorio dentro de la carpeta de skills de Claude. Tienes dos caminos.

Opción A: dile a Claude que lo instale

Abre Claude Code y pega este prompt. Claude clona el repositorio por ti sin que toques la terminal.

Copiar
Instala este skill de deploy en mi Claude Code:
https://github.com/Hainrixz/all-deploy

Clónalo en ~/.claude/skills/all-deploy

Opción B: instalación manual en tu terminal

git clone https://github.com/Hainrixz/all-deploy.git ~/.claude/skills/all-deploy
Copiar comando

¿Por qué en ~/.claude/skills/?

Claude Code busca skills automáticamente en esa carpeta. Una vez que el repositorio está ahí, Claude lo reconoce y puedes usar el comando /all-deploy de inmediato. Sin configuración extra.

03 cómo usarlo

Un comando y listo

Abre Claude Code en la carpeta de tu proyecto y escribe el comando. Eso es todo. All Deploy se encarga del flujo completo — de tu compu a internet sin que tengas que pensar a dónde va cada cosa.

Comando para iniciar el deploy

/all-deploy
Copiar comando

Lo que pasa cuando lo ejecutas

1. Detecta

All Deploy revisa tu proyecto y decide a dónde debe ir.

2. Revisa

Chequeo de seguridad previo — no te deja subir algo roto.

3. Preview

URL de prueba antes de producción. Si se ve bien, continúa.

4. Producción

Deploy final + comando de rollback listo por si lo necesitas.

04 detección inteligente

A dónde va cada proyecto

All Deploy lee tu proyecto y decide la plataforma por ti. No tienes que saber nada de Vercel, Railway ni de servidores. Si es una página, se va a Vercel. Si es un agente, a Railway. Si es algo más pesado, a tu VPS.

Páginas web

Vercel

Landings, frontends, apps de Next.js, Vite o estáticas. Se suben con un par de segundos y quedan detrás de un dominio de Vercel o el tuyo propio.

Agentes y APIs

Railway

Agentes con Claude SDK, APIs de Node o Python, workers y jobs. Railway le pone servidor, base de datos y variables de entorno sin configuración manual.

Proyectos pesados

VPS propio

Docker, cargas de trabajo grandes, o cuando quieres control total. All Deploy genera el docker-compose y te deja el proyecto corriendo en tu servidor.

05 red de seguridad

No te deja romper producción

Subir a producción da nervios por una razón: si algo sale mal, se cae algo que la gente ya está usando. All Deploy mete tres capas entre tu código y el mundo para que puedas dormir.

Revisión previa

Antes de tocar producción, All Deploy corre un chequeo de seguridad — busca secretos en el código, variables expuestas y configuraciones peligrosas.

Preview primero

Primero te deja ver una URL de prueba. Si se ve bien ahí, entonces le das luz verde a producción. Nunca subes a ciegas.

Rollback en un segundo

Si algo sale mal allá afuera, te deja el comando de rollback listo. Un comando y regresas a la versión anterior en cuestión de segundos.
