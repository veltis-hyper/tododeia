5 Habilidades de Claude que Reemplazan tu Office

Si tú usas Excel, PowerPoint, documentos Word o PDFs, pues eso ya se acabó. Cinco habilidades gratuitas que hacen todo eso — instálalas y deja de pagar por apps de oficina.

Qué vas a encontrar

  • PDF — extrae tablas, llena formularios, combina y crea PDFs
  • Excel — fórmulas automáticas, análisis de datos y gráficos
  • Word — documentos profesionales con tablas, imágenes y formato
  • PowerPoint — presentaciones completas en una oración
  • Doc Co-Authoring — escritura colaborativa con Claude

01 pdf

PDF — Adiós a Adobe Acrobat

Reemplaza: Adobe Acrobat, SmallPDF y similares

Extrae tablas, llena formularios, combina documentos y crea PDFs desde cero. Lo que otras aplicaciones te cobran, Claude lo hace con una habilidad.

anthropics/skills/tree/main/skills/pdf

Skill oficial de Anthropic — open source

Descargar SkillVer en GitHub

Qué puedes hacer

  • Extrae texto y tablas de cualquier PDF
  • Llena formularios PDF automáticamente
  • Combina, divide y reorganiza páginas
  • Crea PDFs profesionales desde cero con formato completo

Instalación rápida

claude install-skill https://github.com/anthropics/skills/tree/main/skills/pdf
Copiar comando

Ejemplo: extraer tablas

Extrae datos de un PDF y los organiza en Excel

Extrae todas las tablas de este PDF y crea un archivo Excel con una hoja por tabla.

05 co-authoring

Doc Co-Authoring — Un escritor profesional a tu lado

Reemplaza: Escribir documentos solo

En vez de escribir documentos solo, Claude escribe contigo. Le avientas tu idea, le haces preguntas, entre los dos arman el documento. Es como tener un escritor profesional a tu lado.

anthropics/skills/blob/main/skills/doc-coauthoring/SKILL.md

Skill oficial de Anthropic — open source

Descargar SkillVer en GitHub

Qué puedes hacer

  • Escritura colaborativa — Claude construye contigo, no por ti
  • Desarrollo iterativo sección por sección
  • Revisión con validación de lectura automática
  • Edición dirigida con sugerencias contextuales

bonus

Instala todo de un jalón

Un solo comando para instalar las 5 habilidades. Copia, pega en tu terminal y listo.

Instalar las 5 habilidades

claude install-skill https://github.com/anthropics/skills/tree/main/skills/pdf && claude install-skill https://github.com/anthropics/skills/tree/main/skills/xlsx && claude install-skill https://github.com/anthropics/skills/tree/main/skills/docx && claude install-skill https://github.com/anthropics/skills/tree/main/skills/pptx && claude install-skill https://github.com/anthropics/skills/blob/main/skills/doc-coauthoring/SKILL.md
Copiar comando
