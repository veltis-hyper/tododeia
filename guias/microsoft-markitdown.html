Deja de Quemarte la Cuenta de Claude con PDFs

Cada vez que le das un PDF, un Word o un Excel a Claude directo, él tiene que leer todo el archivo entero — y eso te gasta muchísimo de tu cuenta. Microsoft acaba de soltar una herramienta gratis llamada MarkItDown que deja tus archivos en un formato limpio que Claude sí entiende bien y casi no consume tokens.

01 qué es esto

Un Traductor de Archivos Para Claude

Imagínalo así:

Claude es muy inteligente leyendo texto limpio, pero se cansa cuando le das archivos pesados como PDFs o Words. MarkItDown es como un traductor: agarra esos archivos difíciles y se los pasa a Claude ya masticaditos, en texto simple. Claude lo lee rapidísimo y casi no gasta tu cuenta.

Es gratis, lo hizo Microsoft, ya tiene más de 100 mil likes en GitHub, y lo mejor: no necesitas saber programar para usarlo. Solo le dices a Claude Code que lo instale por ti y listo.

  • Cuando le das un PDF a Claude, tiene que leer todo el archivo entero — eso gasta muchísimo de tu cuenta sin que te des cuenta.
  • MarkItDown agarra el PDF (o Word, Excel, PowerPoint, imagen, audio, hasta videos de YouTube) y lo deja en texto limpio.
  • Claude entiende el texto limpio rapidísimo y casi no gasta tokens.
  • Resultado: tu cuenta de Claude te dura más y las respuestas salen mejor porque ya no se pelea con el archivo.

Estos archivos los entiende:

  • PDF
  • Word (.docx)
  • Excel (.xlsx)
  • PowerPoint (.pptx)
  • Imágenes con texto adentro
  • Audios (los transcribe solito)
  • Videos de YouTube (por el link)
  • HTML, CSV, JSON, XML y archivos ZIP

Herramienta oficial de Microsoft — github.com/microsoft/markitdown

02 instalar

Le Dices a Claude Que Lo Instale Por Ti

No necesitas saber de programación, ni terminal, ni comandos raros. La magia es esta: copias el prompt de abajo, lo pegas en Claude Code (o Codex, o Cowork, lo que uses), y Claude se encarga de todo — baja la herramienta del GitHub de Microsoft y la instala solito en tu computadora.

Pega esto en Claude Code o Codex

Instala la herramienta MarkItDown de Microsoft desde https://github.com/microsoft/markitdown en mi computadora. Después úsala cada vez que te pida convertir un archivo (PDF, Word, Excel, PowerPoint, imagen, audio o video) a Markdown antes de leerlo. Avísame cuando termines de instalarla.

03 cómo usarlo

Copia un Prompt y Pruébalo

Ya está instalado. Ahora, en vez de arrastrarle el PDF directo a Claude, le dices: “usa MarkItDown para convertir este archivo”. Claude lo traduce primero a texto limpio y después sí lo lee. Ese paso extra te ahorra un montón de tokens.

Convertir un PDF a Markdown
