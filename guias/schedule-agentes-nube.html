Schedule: Agentes en la Nube

Crea agentes automáticos que trabajan para ti mientras duermes. Con /schedule, Claude ejecuta tareas recurrentes en la nube de Anthropic — no necesitas dejar tu computadora encendida.

Qué vas a aprender

  • Qué es /schedule — agentes en la nube que corren aunque cierres tu laptop.
  • Un solo comando — la sintaxis es lenguaje natural: frecuencia + tarea + integraciones en una línea.
  • /schedule vs /loop — cuándo usar cada uno y por qué /schedule cambia las reglas.
  • Casos de uso reales — CI, documentación, reportes, monitoreo y más.
  • Schedule + skills — combina tareas programadas con habilidades para automatizaciones completas.

01 qué es /schedule

Tu agente en la nube

/schedule crea trabajos recurrentes que corren en la nube de Anthropic. A diferencia de /loop (que corre en tu máquina local), con /schedule puedes cerrar tu laptop, irte a dormir, irte al gym — y Claude sigue trabajando para ti.

Anthropic ya lo usa internamente para resolver fallas de CI automáticamente, actualizar documentación y correr automatizaciones que necesitan existir más allá de una laptop cerrada.

El comando

/schedule

02 cómo usarlo

Un comando, una línea

La sintaxis es lenguaje natural. Escribes /schedule seguido de lo que quieres que Claude haga, cada cuándo, y qué herramientas usar. Todo en una sola línea. Claude crea el trabajo en la nube y lo ejecuta en el horario que definiste.

Ejemplo real de Anthropic

Este es el ejemplo que usa el equipo de Anthropic internamente — revisa PRs del día, actualiza docs y notifica por Slack.

Copiar
/schedule a daily job that looks at all PRs shipped since yesterday and update our docs based on the changes. Use the Slack MCP to message #docs-update with the changes

Resolver fallas de CI

/schedule every 2 hours, check CI status on the main branch. If any check failed, diagnose the issue, create a fix, and open a PR

Reporte diario por correo

/schedule daily at 7am, summarize all GitHub issues opened yesterday and send the summary to my email via Gmail MCP

Monitoreo de sitio web

/schedule every 6 hours, check if tododeia.com is responding correctly and if load time is under 3 seconds. Alert me on Slack if anything is off

Funciona con Claude Code y Claude Cowork.

Puedes escribir /schedule tanto en tu terminal con Claude Code como en Claude Desktop (Cowork). El resultado es el mismo: un agente en la nube que trabaja para ti 24/7.

03 /schedule vs /loop

La nube vs tu máquina

/loop — Local

  • Corre en tu computadora
  • Necesitas dejar la máquina encendida
  • Se detiene si cierras la laptop
  • Ideal para tareas puntuales o sesiones largas

/schedule — Nube

  • Corre en los servidores de Anthropic
  • Tu máquina puede estar apagada
  • Sigue corriendo aunque cierres todo
  • Ideal para automatizaciones recurrentes 24/7

¿Cuándo usar cada uno?

Si necesitas algo ahora mismo y puedes dejar tu máquina corriendo, usa /loop. Si necesitas algo recurrente que corra aunque estés dormido, usa /schedule.

04 casos de uso

Qué puedes automatizar

Arreglar código

Monitorea tu CI, detecta fallas y crea PRs con fixes automáticamente. Tu pipeline se arregla solo mientras duermes.

Actualizar documentación

Revisa los PRs del día y actualiza los docs correspondientes. Tu documentación siempre está al día sin esfuerzo.

Mandar reportes

Genera resúmenes periódicos de métricas, actividad del proyecto o estado de tareas y envíalos por Slack o email.

Monitorear páginas web

Vigila URLs, detecta cambios de contenido o caídas, y te notifica o toma acción automáticamente.

Monitoreo semanal de competencia

Ejemplo avanzado que combina web scraping, análisis y notificación automática.

Copiar
/schedule every Monday at 8am, visit the pricing pages of [competitor1.com] and [competitor2.com], compare their prices with our file /docs/precios.csv, and if any competitor dropped more than 10%, send me a Slack message in #alerts with the details

05 schedule + skills

Automatizaciones completas

/schedule se vuelve más poderoso cuando lo combinas con skills (habilidades de Claude Code). El skill define qué sabe hacer Claude. /schedule define cuándo lo hace.

SEO + /schedule

Auditoría SEO semanal automática de tu sitio.

Copywriter + /schedule

Revisión diaria de contenido nuevo en tu blog.

Ads + /schedule

Monitoreo de campañas cada 6 horas.
