01 explicado fácil

Qué es Skill Vault

Imagina esto:

Tienes un montón de juguetes regados por toda tu casa. Unos son carritos, otros son muñecos, otros son pelotas. No sabes cuáles están rotos y no encuentras el que necesitas cuando lo quieres.

Skill Vault es como una caja mágica que hace tres cosas:

  1. Revisa cada juguete para asegurarse de que no está roto ni es peligroso.
  2. Los guarda en cajoncitos — carritos con carritos, pelotas con pelotas.
  3. Te dice cuál usar — le dices "quiero jugar a las carreras" y te pasa el carrito correcto.

Eso mismo hace con tus habilidades de Claude Code. Las revisa, las organiza y te recomienda cuáles usar.

Importante

Skill Vault no es un skill — es un proyecto completo. Es un agente que vive en su propia carpeta y se encarga de administrar todas las habilidades que le metas. Tú solo le avientas un skill y él hace todo lo demás.

02 instalación

Cómo Descargarlo

Opción 1 — Si tienes git (la más rápida)

Paso 1. Abre tu terminal. En Mac es la app "Terminal". En Windows es "PowerShell" o "CMD".

Paso 2. Copia y pega este comando. Él descarga la carpeta, entra en ella y abre Claude Code.

Copia y pega esto en tu terminal

git clone https://github.com/Hainrixz/skill-vault.git && cd skill-vault && claude
Copiar comando

Opción 2 — Si no tienes git (descarga directa)

Paso 1. Dale clic al botón "Descargar ZIP" de arriba. Se va a descargar un archivo .zip a tu computadora.

Paso 2. Descomprime el ZIP. En Mac le das doble clic. En Windows, clic derecho → "Extraer todo". Te va a crear una carpeta llamada skill-vault-main.

Paso 3. Abre tu terminal y navega a esa carpeta. En Mac puedes arrastrar la carpeta a la app Terminal. O escribe:

Entra a la carpeta y abre Claude

cd ~/Downloads/skill-vault-main && claude
Copiar comando

No necesitas instalar nada extra

No hay npm install. No hay pip. No hay configuración. Solo necesitas tener Claude Code instalado en tu computadora. Descargas la carpeta, abres Claude Code adentro y el agente se activa solo.

03 uso básico

Cómo Se Usa (Paso a Paso)

1. Encuentras un skill en internet — en Twitter, YouTube, Instagram, donde sea. Puede ser un link a GitHub, un bloque de código que alguien compartió, o una URL de un repositorio.

2. Abres Claude Code dentro de la carpeta de Skill Vault — si ya lo tienes abierto, perfecto. Si no, abre tu terminal y escribe claude desde la carpeta del proyecto.

3. Le escribes /vault-add y le pegas el skill — le das el link o el código directamente en el chat de Claude. Él lo toma de ahí.

4. Él lo revisa automáticamente — lo analiza con 13 puntos de seguridad y te dice si es seguro, si tiene riesgo o si mejor ni lo toques. No tienes que hacer nada, solo esperar.

5. Lo organiza solo en la carpeta correcta — diseño, automatización, código, investigación, lo que sea. Tú no mueves nada.

6. Cuando necesites un skill, le preguntas — le escribes /vault-recommend y le describes qué estás construyendo. Él busca en tu biblioteca y te dice exactamente cuáles usar.

04 comandos

Tus 7 Comandos

Estos comandos los escribes directo en el chat de Claude Code (dentro de la carpeta de Skill Vault). Solo escribe el comando, dale enter y el agente hace el resto.

ComandoPara qué sirve
/vault-addLe pegas un link o código de un skill y lo guarda en tu bóveda
/vault-searchBuscas un skill por nombre — ejemplo: "busca diseño"
/vault-recommendLe dices qué estás haciendo y te dice qué skills usar
/vault-discoverBusca skills nuevos en internet y los importa directo
/vault-listTe muestra todos tus skills organizados por carpeta
/vault-statsTe dice cuántos skills tienes y cuáles usas más
/vault-removeBorra un skill que ya no quieres tener guardado

05 seguridad

Análisis de 13 Puntos

Cada vez que agregas un skill, Skill Vault lo revisa con 13 checks de seguridad antes de guardarlo. Busca cosas como comandos que pueden borrar archivos, código que intenta robar tus contraseñas, o trucos escondidos que no se ven a simple vista.

Si algo se ve raro, te avisa y te pregunta antes de guardarlo. Nunca mete algo peligroso a tu bóveda sin tu permiso.

Cada skill recibe una calificación

SAFE

Todo bien — úsalo con confianza

CAUTION

Revisa antes de usar — tiene algo raro

DANGEROUS

No lo uses — puede dañar tu equipo
