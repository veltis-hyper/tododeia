Paso 1 · instalar

Dos caminos · uno con terminal · otro sin tocar nada

Hay 2 caminos para instalar la skill. El Camino A es el comando oficial del README — un solo npx que la deja disponible globalmente. El Camino B es para quien prefiere no tocar la terminal: abrís Claude Code en cualquier carpeta y le pegás un prompt para que la skill se instale sola. Los dos llegan al mismo lugar.

Camino A · oficial · 1 comando

npx skills add — el comando que recomienda el README

Si tenés Node instalado, este es el camino más corto.

Es el comando que el README oficial te muestra primero. Lo corrés desde tu terminal (no adentro de Claude Code todavía), se instala globalmente, y queda disponible la próxima vez que abrás Claude Code en cualquier carpeta. Si nunca instalaste Node, mirá la sección de instalar Claude Code primero — ya viene con todo.

  1. 01

    Abrí tu terminal (Mac · Linux · Windows)

    En Mac apretás Cmd+Espacio y escribís Terminal. En Windows abrís PowerShell desde el menú inicio. En Linux ya sabés. No necesitás estar adentro de ninguna carpeta especial — la skill se instala global.

  2. 02

    Pegá el comando y dale Enter

    Copiá el comando de la card de abajo, pegalo en tu terminal y apretá Enter. Si te pide confirmar la primera vez (npx te puede preguntar si querés bajar el paquete), respondés y. Tarda unos segundos según tu internet.

  3. 03

    Abrí Claude Code y ya está

    La próxima vez que abrás Claude Code (claude en terminal o la app de escritorio), la skill ya está disponible. No tenés que activarla manual — Claude la detecta y la usa cuando le pidas un diseño.

Lo que ganás · global, una sola vez

Como se instala global, la próxima vez que arranques Claude Code en cualquier proyecto la skill está ahí. No tenés que repetir la instalación por carpeta. Si después querés sacarla, hay un comando npx skills remove alchaincyf/huashu-design — pero la mayoría la deja puesta porque consume cero tokens cuando no la usás.

Paso 2 · explorar · 7 capacidades reales

Las 7 cosas que sabe diseñar — timing real, no del reel

El script del video habla de 5 cosas, pero el README oficial documenta 7. Las 5 del script son las más vistosas para mostrar; las 2 bonus (asesor de dirección de diseño y crítica de 5 dimensiones) son las que más te ahorran tiempo cuando estás trabado. Acá están las 7 con el timing real que reporta el autor — algunos son más lentos de lo que el script dejó entender, pero todos siguen siendo mucho más rápidos que armarlos a mano.

Capacidad 01Tiempo · 10–15 minutos

Prototipo interactivo de iPhone / Web

HTML single-file con el marco real de iPhone (bezel, status bar, home indicator). Los botones funcionan de verdad — podés tocarlos, navegar entre pantallas, usar la demo como si fuera la app instalada.

Cuándo usarlo

Cuando estás validando una idea con un cliente o socio y necesitás que toque algo, no que mire un mockup estático. Abrís el HTML en cualquier navegador y se lo mostrás.

Para quién

Founders pre-producto, freelancers presentando a clientes, agencias armando pitches sin tener que entrar al pipeline de Figma.

Capacidad 02Tiempo · 15–25 minutos

Slide decks · HTML deck + PPTX editable

Dos formatos al mismo tiempo: un HTML deck navegable con flechas y un .pptx que abrís en PowerPoint o Keynote y editás como cualquier presentación. No son PDFs planos que Claude te tira normalmente — son archivos editables de verdad.

Cuándo usarlo

Pitches de inversión, keynotes de conferencia, training interno, reporte trimestral. Cualquier cosa que necesite formato presentación profesional, no un Google Docs.

Para quién

Cualquiera que arme decks a mano hoy y quiera saltarse las primeras 4 horas de "empezar la estructura". Refinar después es trivial.

Capacidad 03Tiempo · 8–12 minutos

Motion design · MP4 + GIF + audio

Video MP4 (25fps o 60fps según le pidas), versión GIF opcional para WhatsApp/Twitter, y música de fondo (BGM) que la skill elige por mood. Animaciones gráficas, transiciones, efectos especiales — todo armado sin que vos toques After Effects.

Cuándo usarlo

Anuncios cortos, explainers de producto, intros de YouTube, posts animados para LinkedIn. Cuando un video de 30–60 segundos cuenta la historia mejor que un carrusel de imágenes.

Para quién

Creadores de contenido sin team de motion design, marketers que necesitan reels semanales sin pagar editor.

Capacidad 04Tiempo · ~10 minutos

Infografías print-quality · PDF · PNG · SVG

Infografía exportable en 3 formatos: PDF para imprimir, PNG para redes, SVG para que la edites después en cualquier editor vectorial. La skill respeta tu marca (si le pasás colores o logo) e investiga el tema antes de armar.

Cuándo usarlo

Reportes para clientes, ebooks lead-magnet, posts educativos en LinkedIn, material para charlas. Cuando los datos importan más que el storytelling.

Para quién

Consultores armando reportes para clientes, educadores online, equipos de marketing B2B con thought leadership.

Capacidad 05Tiempo · +10 minutos sobre la capacidad base

3 versiones por cada diseño · la favorita del autor

Cada vez que le pedís algo (prototipo, deck, motion, infografía) te devuelve 3 versiones side-by-side con parámetros editables. No tenés que pedir variaciones — vienen por default.

Cuándo usarlo

Siempre que no tengas claro qué dirección visual querés. Mirás las 3, elegís la que más te late, y a partir de ahí refinás.

Para quién

Cualquiera que sufre el "y si lo hacíamos distinto" — esto te lo resuelve adelante, no después de 2 días trabajando una sola versión.

Capacidad 06BonusTiempo · 5 minutos

Bonus · Asesor de dirección de diseño

Antes de empezar a diseñar, le podés preguntar "¿qué dirección visual le va a esto?" y la skill te muestra 5 escuelas (minimalismo, brutalismo, neumorfismo, glass, retro) cruzadas con 20 filosofías de diseño y te ofrece 3 demos visuales para que decidas el style. Después de eso, todo lo que pidas hereda esa dirección.

Cuándo usarlo

Cuando tenés la idea pero no la estética. Te ahorra hacer 10 prototipos antes de saber qué estilo querías.

Para quién

Founders no-diseñadores, ejecutivos armando decks de board, cualquiera que envidia el "buen ojo" de los diseñadores y no sabe describirlo.

Capacidad 07BonusTiempo · 3 minutos

Bonus · Crítica de 5 dimensiones

Le pasás un diseño tuyo (capturas, link, HTML que ya armaste con cualquier herramienta) y la skill te devuelve un radar chart con 5 ejes (jerarquía visual, contraste, balance, claridad, originalidad), un bloque Keep (lo que está bien), un Fix (lo que urge cambiar) y un Quick Wins (lo que mejora con 5 minutos de trabajo).

Cuándo usarlo

Antes de mostrar algo importante. Pre-pitch, pre-publish, pre-presentación. Te saca el ego del medio y te dice qué arreglar.

Para quién

Cualquiera que diseña en soledad y necesita un segundo par de ojos honesto sin agendar feedback session con un diseñador real.

07 · Crítica de 5 dimensiones (bonus)

Pasale algo que ya armaste y te lo critica honesto. Radar chart con 5 ejes + Keep / Fix / Quick Wins.

Copiar
Te paso este diseño para que me hagas la crítica de 5 dimensiones:

- Quick Wins: 2-3 cosas que mejoran mucho con 5 minutos de trabajo.

Sé honesto — si está flojo en algún eje, decímelo sin endulzar.

La feature favorita · merece sección propia

3 versiones por diseño · por default · sin tener que pedirlo

Esta capacidad merece su propia sección porque es la que más cambia cómo trabajás. La mayoría de las herramientas te devuelven 1 versión y vos pedís cambios. Huashu Design por default te da 3 versiones cada vez que pedís algo — sin que tengas que pedirlo. La diferencia parece chica pero cambia el flow entero.

Pensalo así: cuando un diseñador humano te muestra una sola versión, sabés que te está vendiendo "su" idea. Cuando te muestra 3, te está dando opciones — y vos elegís. Huashu Design replica ese segundo modelo por default. Cada prototipo, cada deck, cada infografía sale en 3 sabores side-by-side.

El ahorro no es solo de tiempo — es de tokens. En lugar de iterar 5 veces sobre una sola versión (quemando contexto cada turno), iteras 1 vez sobre la que más te gustó de las 3. Es 2-3x menos consumo de tu cuota mensual por diseño terminado.

Si las 3 no te convencen, podés pedir 3 nuevas con notas — pero en la práctica eso pasa pocas veces. La skill es buena justamente porque las 3 versiones que tira la primera vez ya cubren un espectro amplio. Vos ajustás de ahí.

Versión A

La dirección más segura · estética convencional · resuelve el brief sin riesgos.

Versión B

Un giro inesperado · mismo brief pero con un ángulo creativo que no se te hubiera ocurrido.

Versión C

El experimento · va por la dirección más arriesgada · funciona para 1 de cada 3 casos.

5 trampas honestas

Lo que el reel no te dijo — para que no te pegues contra la pared

01

El timing real de infografías no es 30 segundos · es ~10 minutos

El video dice "infografías en menos de 30 segundos" para que el reel funcione. La realidad del README es ~10 minutos por infografía print-quality con los 3 exports (PDF · PNG · SVG). Sigue siendo muchísimo más rápido que armarla a mano, pero si estás esperando que aparezca en 30 segundos te vas a frustrar. Calculá 5-15 minutos por capacidad.

02

No es exclusiva de Claude Code · también corre en Cursor · Trae · Hermes · OpenClaw

El video habla solo de Claude Code porque ese es el ecosistema de tododeia. Pero la skill es multi-tool: el README oficial lista que también funciona con Cursor, Trae, Hermes y OpenClaw. Si pagás Cursor en lugar de Claude, la misma skill te sirve igual — no hace falta cambiar de herramienta.

03

El autor mismo dice "es un skill de 80 puntos · no un producto de 100"

Verbatim del README: "This is an 80-point skill, not a 100-point product". Es honestidad explícita del autor (花叔 / @AlchainHust). Para branding desde cero (sin ningún input visual previo), la calidad baja a 60-65 puntos. Para producción final crítica, sigue necesitando edición humana. Pensala como acelerador, no reemplazo.

04

Sin round-trip PPTX → Figma · animaciones tipo Framer Motion fuera de scope

Los .pptx que genera son editables en PowerPoint y Keynote, pero no exportan a Figma con capas separadas (no hay round-trip). Las animaciones tipo Framer Motion (físicas, gestos avanzados, transiciones declarativas en React) también están explícitamente fuera de scope — para eso usás cult-ui o motion-primitives directo.

05

Docs originales en chino · esta guía es la 3ra capa de traducción

El autor es de China continental, los docs originales están en mandarín. El README en inglés es traducción paralela hecha por el autor (no por la comunidad). Esta guía en español es la 3ra capa — si encontrás algo que no cierra, contrastá con el README en inglés primero, y con el chino original como autoridad final.

Por dónde empezar si nunca instalaste una skill

Por dónde empezar si nunca instalaste una skill: (1) verificá que tengas Claude Code corriendo — si no, la guía /community/instalar-claude-code te lleva paso a paso, (2) seguí el Camino A (1 comando npx) — si nunca tocaste npx, andá al Camino B (le pedís a Claude que lo instale por vos), (3) probá el prompt 01 (prototipo de iPhone) primero — es el más visual y el que más rápido te muestra que la skill funciona, (4) después de eso, leé la sección Las 7 cosas para ver qué capacidades te van a servir según lo que vos hagas, (5) si te trabás, leé los 5 gotchas — la mitad de los problemas comunes están ahí.

Para quién no aplica esta página

Para quién no aplica esta página: usuarios sin Claude Code instalado (necesitás la CLI o la app de escritorio — no funciona desde el chat web de Claude). Diseñadores profesionales que necesitan round-trip a Figma con capas editables (esta skill no lo soporta, mejor mirá la guía de Claude Design oficial). Equipos en industrias reguladas (legal · salud) donde el código del modelo debe estar auditado y certificado — Huashu Design es MIT comunitaria, no tiene certificaciones de compliance. Y si solo querés 1 capacidad específica (ej. solo motion design), tal vez te conviene mirar 5-skills-diseno-claude que separa cada oficio en su propia skill más liviana.
