Las Tres Herramientas Claude Code

este proyecto junta 3 repos para resolver un problema real de vibecoding: pasar de ideas sueltas a un sistema repetible donde planeas bien, ejecutas rápido y mantienes calidad.

Qué vas a lograr con este stack

  • ordenar el trabajo en tareas claras para que Claude Code no se descarrile.
  • reducir contexto roto con un flujo de especificación y ejecución más estructurado.
  • acelerar iteraciones con templates, comandos y agentes ya listos.
  • subir calidad de entrega sin volverte dependiente de un solo prompt gigante.

Las 3 herramientas (y por qué te convienen)

1) Vibe Kanban

tablero y workspace para coordinar agentes de código, revisar diffs y ejecutar por tickets.

  • ideal cuando ya tienes varias tareas corriendo en paralelo.
  • mejora visibilidad y control del estado real del trabajo.
abrir repo

2) Get Shit Done (GSD)

sistema de meta-prompting y spec-driven dev para mantener resultados consistentes en Claude Code.

  • útil cuando tu contexto se degrada y las respuestas se vuelven inconsistentes.
  • te da comandos y estructura para planear y ejecutar por fases.
abrir repo

3) Claude Code Templates

catálogo de agentes, comandos, hooks y MCPs listos para instalar y acelerar tu setup.

  • perfecto para evitar arrancar de cero cada proyecto.
  • te ayuda a estandarizar calidad entre equipos o clientes.
abrir repo

Cómo combinarlas (flujo recomendado)

  1. configura base de agentes/comandos con Claude Code Templates.
  2. usa GSD para traducir ideas a roadmap, fases y planes ejecutables.
  3. opera la ejecución diaria en Vibe Kanban con tickets, workspaces y revisión de diffs.
  4. itera semanalmente según feedback real, no solo según percepción.

Realidad del uso

estas herramientas no reemplazan criterio. lo que sí hacen es darte un sistema que reduce caos y mejora consistencia. si hoy sientes que "Claude a veces sí y a veces no", este combo te ayuda a estabilizar.
