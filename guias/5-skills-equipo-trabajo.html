01 skill creator

El que Crea Habilidades Desde Cero

La Fábrica105k+
Imagina que todos los días haces lo mismo en tu trabajo: generas un reporte, mandas un email con cierto formato, revisas datos de cierta forma. Con Skill Creator, le dices a Claude exactamente qué haces, Claude lo prueba contigo paso a paso, y al final te lo empaqueta en un archivo. La próxima vez que necesites hacer esa tarea, Claude ya sabe cómo hacerla perfectamente. Es como entrenar a un asistente una vez y que nunca se le olvide.

Por qué importa

Esta habilidad es oficial de Anthropic, los creadores de Claude. No es un proyecto de alguien random en internet. Anthropic la diseñó para que cualquier persona pueda crear sus propias herramientas personalizadas sin saber programar. Le describes lo que quieres en español, en lenguaje normal, y Claude te la construye lista para usar. La vuelves a usar cuando quieras.

Qué hace exactamente

  • Te entrevista para entender exactamente qué necesitas automatizar
  • Crea un borrador de la habilidad basado en lo que le dijiste
  • La prueba contigo con casos reales para verificar que funcione
  • Te muestra los resultados en tu navegador para que los revises
  • La mejora basándose en tu retroalimentación hasta que quede perfecta
  • Optimiza la descripción para que Claude la encuentre automáticamente

Cómo se usa — paso a paso

  1. Abre tu terminal con Claude Code
  2. Dile a Claude: "Quiero crear una habilidad que haga [lo que necesitas]"
  3. Claude te va a hacer preguntas sobre tu tarea. Contesta todo con detalle
  4. Claude escribe un borrador del SKILL.md y te propone casos de prueba
  5. Revisa los resultados. Si algo no te convence, dile qué cambiar
  6. Cuando estés satisfecho, Claude te deja la habilidad lista para usar para siempre

02 write a skill

El que Te Deja la Habilidad Bien Hecha

El Ingeniero15k+
Skill Creator te arma la habilidad rápido, pero Write a Skill es el ingeniero que se asegura de que esté bien construida. Piensa en la diferencia entre una casa que armaste tú con videos de YouTube y una que diseñó un arquitecto. Las dos sirven, pero la del arquitecto tiene mejores cimientos, mejor estructura y no se te va a caer en un mes. Write a Skill toma tu idea, te hace preguntas sobre qué exactamente necesitas, y te produce un archivo SKILL.md con la estructura correcta, descripciones claras y buenas prácticas. Un comando y es todo.

Por qué importa

Tiene más de 15 mil estrellas en GitHub. La comunidad la usa porque produce habilidades que siguen las mejores prácticas: descripciones bien escritas para que Claude las encuentre automáticamente, estructura organizada con secciones claras, y archivos de referencia separados cuando hace falta. Si vas a crear habilidades que quieres compartir o usar a largo plazo, esta es la forma correcta de hacerlo.

Qué hace exactamente

  • Te pregunta qué tarea cubre la habilidad y qué casos debe manejar
  • Investiga si necesita scripts ejecutables o solo instrucciones
  • Escribe el SKILL.md con la estructura correcta: nombre, descripción, workflows y ejemplos
  • La descripción incluye triggers claros para que Claude sepa cuándo usarla
  • Mantiene el archivo bajo 100 líneas y divide en archivos separados si es necesario
  • Revisa contigo el resultado antes de darlo por terminado

Cómo se usa — paso a paso

  1. Abre tu terminal con Claude Code
  2. Corre: npx skills@latest add mattpocock/skills/write-a-skill
  3. Una vez instalada, dile a Claude: "/write-a-skill" o "quiero crear una habilidad"
  4. Claude te pregunta qué necesitas. Contesta con todos los detalles
  5. Claude escribe el borrador y te lo muestra para revisión
  6. Cuando estés conforme, la habilidad queda instalada y lista

Cómo se usa — paso a paso

04 grill me

El que Te Hace las Preguntas Difíciles

El Interrogador15k+
Todos hemos tenido esa experiencia: empiezas a construir algo, llevas semanas trabajando, y de repente te das cuenta de que se te olvidó algo fundamental. Que no pensaste en cómo manejar los pagos. Que no consideraste qué pasa si el usuario pierde internet. Que tu idea tiene un hueco gigante que no viste al principio. Grill Me es como tener un socio brutalmente honesto que ANTES de que pierdas tiempo te sienta y te dice: "A ver, explícame tu idea. ¿Qué pasa si...? ¿Y esto lo pensaste? ¿Y aquí qué haces?". Te obliga a contestar las preguntas incómodas que tú solo nunca te harías.

Por qué importa

La mayoría de los proyectos no fracasan por mala ejecución — fracasan porque nadie se hizo las preguntas correctas al principio. Esta habilidad te ahorra semanas (o meses) de trabajo desperdiciado. Contestas una vez, piensas bien tu plan, y cuando empiezas a construir ya sabes exactamente qué estás haciendo y por qué.

Qué hace exactamente

  • Te entrevista de forma agresiva sobre cada aspecto de tu plan o idea
  • Baja por cada rama del árbol de decisiones, una por una
  • Te obliga a resolver dependencias entre decisiones antes de avanzar
  • Para cada pregunta, te da su recomendación — no te deja solo
  • Si la respuesta está en tu código, la busca él en vez de preguntarte
  • No para hasta que los dos tengan un entendimiento compartido completo

Cómo se usa — paso a paso

  1. Abre tu terminal con Claude Code
  2. Corre: npx skills@latest add mattpocock/skills/grill-me
  3. Una vez instalada, dile a Claude: "/grill-me" seguido de tu idea o plan
  4. Claude te va a hacer preguntas una por una — contesta con honestidad
  5. Cada pregunta viene con la recomendación de Claude para que no te quedes atorado
  6. Cuando termina, tienes un plan sólido con todos los huecos tapados

05 write a prd

El Arquitecto de tu Proyecto

El Arquitecto15k+
Un PRD (Product Requirements Document) es el plano de tu proyecto. Imagina que quieres construir una casa pero en vez de llegar con un "quiero una casa bonita", llegas con un plano detallado que dice exactamente cuántos cuartos, de qué tamaño, dónde van las ventanas, qué materiales usar y en qué orden construir. Write a PRD hace exactamente eso con tu idea de software. Le cuentas tu idea (por suelta que sea), Claude te entrevista a fondo, y al final te deja un documento profesional completo — con problema, solución, historias de usuario, decisiones técnicas y plan de pruebas — guardado como un issue en GitHub.

Por qué importa

Este es la cereza del pastel. Entras con una idea suelta y sales con un documento bien hecho que cualquier desarrollador (o Claude) puede leer y ejecutar sin preguntarte nada. Es la diferencia entre decirle a Claude "hazme una app" y darle un plano de 16 secciones con cada detalle resuelto. El resultado siempre es mejor cuando el plan es mejor.

Qué hace exactamente

  • Te pide una descripción larga y detallada del problema que quieres resolver
  • Explora tu código para verificar lo que dices y entender el estado actual
  • Te entrevista sin piedad sobre cada aspecto del plan hasta llegar a un entendimiento compartido
  • Diseña los módulos principales que hay que construir o modificar
  • Busca oportunidades de crear módulos profundos que se puedan probar de forma aislada
  • Genera el PRD completo y lo sube como un GitHub Issue listo para ejecutar

Cómo se usa — paso a paso

  1. Abre tu terminal con Claude Code
  2. Corre: npx skills@latest add mattpocock/skills/write-a-prd
  3. Una vez instalada, dile a Claude: "/write-a-prd" o "quiero hacer un PRD"
  4. Describe tu idea con todo el detalle que puedas — entre más, mejor
  5. Claude va a investigar tu código y hacerte preguntas sobre cada detalle
  6. Cuando termina, te genera un PRD completo con: problema, solución, user stories, decisiones de implementación, plan de pruebas y lo sube a GitHub

Preguntas frecuentes

¿Necesito saber programar?

No. Las 5 habilidades funcionan con lenguaje natural. Le hablas a Claude en español y él hace todo. Lo único que necesitas es tener Claude Code instalado y una terminal abierta.

¿Cuál es la diferencia entre Skill Creator y Write a Skill?

Skill Creator (de Anthropic) es más interactivo: te entrevista, prueba la habilidad contigo y la itera hasta que quede perfecta. Write a Skill (de Matt Pocock) es más directo: te hace las preguntas necesarias y te produce un SKILL.md con la estructura correcta. Los dos sirven para lo mismo pero con enfoques diferentes. Usa el que prefieras.

¿Qué es skillsmp.com?

Es un marketplace con más de 66 mil habilidades creadas por la comunidad de Claude Code. Buscas lo que necesitas, copias el comando de instalación y listo. No necesitas cuenta ni pagar nada.

¿Puedo usar Grill Me y Write a PRD para cualquier idea?

Sí. Grill Me funciona para cualquier plan o idea — no tiene que ser de software. Write a PRD está más enfocado en proyectos de software y genera un documento técnico que se sube a GitHub como un issue. Si tu proyecto no es de software, Grill Me es la mejor opción.

¿Funcionan en Claude Desktop o solo en Claude Code?

Las habilidades se instalan en Claude Code (la terminal). Claude Desktop no soporta skills todavía. Pero el PRD que genera Write a PRD lo puedes usar en cualquier lugar porque es un documento de texto.
