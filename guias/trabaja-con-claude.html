Trabaja con Claude

Guía simple para entender las 3 formas de trabajar con Claude — el chat, Computer Use y Claude Code. Cada una resuelve un tipo de problema distinto. Aquí aprendes cuándo usar cuál.

Qué vas a aprender

  • Las 3 formas de trabajar con Claude — chat, Computer Use y Claude Code, explicadas sin tecnicismos.
  • Cuándo usar cada una — qué tipo de tareas resuelve mejor cada modo.
  • Cómo empezar hoy — pasos concretos para probar cada forma sin experiencia previa.

01 introducción

3 formas, 1 mismo Claude

Claude no es solo un chatbot. Es un sistema completo con tres modos de interacción, cada uno diseñado para un tipo de trabajo diferente. Piénsalo como tener tres herramientas en una — escoges la que necesitas según la tarea.

La mayoría de la gente solo conoce el chat. Pero las otras dos formas — Computer Use y Claude Code — son donde ocurre la magia para trabajo real.

El Chat

Tú preguntas, Claude responde. Conversación directa.

Computer Use

Claude controla tu computadora. Hace clicks, escribe, navega.

Claude Code

Claude trabaja dentro de tu proyecto. Lee, escribe y ejecuta código.

02 modo

El Chat — la conversación

Este es el Claude que la mayoría conoce. Abres claude.ai o la app de Claude Desktop, escribes algo y Claude te responde. Es una conversación — como WhatsApp pero con una IA que realmente entiende lo que le dices.

Para qué es perfecto

  • Preguntas rápidas y explicaciones — "¿qué es una API?", "explícame este concepto".
  • Escritura y edición — correos, posts, documentos, traducciones.
  • Análisis de archivos — sube un PDF, imagen o CSV y Claude lo analiza.
  • Lluvia de ideas — brainstorming, estrategia, planificación.
  • Ayuda con código — pega un snippet y pide que lo explique, corrija o mejore.

Dónde usarlo

  • claude.ai — desde el navegador, en cualquier dispositivo.
  • Claude Desktop — app nativa para Mac y Windows.
  • App móvil — iOS y Android.

Lo que no puede hacer

  • No puede abrir apps ni navegar internet por ti.
  • No puede editar archivos directamente en tu computadora.
  • No puede ejecutar código ni hacer deploys.

03 modo

Computer Use — el control remoto

Con Computer Use, Claude ve tu pantalla y controla tu computadora. Mueve el mouse, hace clicks, escribe texto, navega entre ventanas. Es como darle acceso remoto a tu escritorio — pero con una IA que entiende lo que está viendo.

Esto es diferente al chat: Claude no solo te dice qué hacer, lo hace por ti. Tú le describes la tarea y observas mientras la ejecuta.

Para qué es perfecto

  • Tareas repetitivas en apps — llenar formularios, mover archivos, organizar carpetas.
  • Navegar sitios web — buscar info, llenar registros, extraer datos.
  • Flujos multi-app — copiar datos de un lugar a otro entre diferentes programas.
  • Testing visual — verificar cómo se ve una página, encontrar bugs de interfaz.
  • Tareas que requieren una interfaz gráfica — cualquier cosa que necesite clicks.

Dónde usarlo

  • Claude Desktop — activa Computer Use desde la app.
  • API — para automatizaciones avanzadas.

Lo que no puede hacer

  • No es ideal para tareas que requieren precisión de código (usa Claude Code para eso).
  • Puede ser más lento que hacer las cosas manualmente para tareas simples.
  • Necesita supervisión — a veces interpreta mal lo que ve en pantalla.

Cuándo elegir Computer Use sobre el chat

Si la tarea requiere interactuar con una interfaz — hacer clicks, llenar campos, navegar entre ventanas — Computer Use es la opción. El chat solo puede decirte los pasos; Computer Use los ejecuta.

04 modo

Claude Code — el compañero de desarrollo

Claude Code es un agente que vive en tu terminal. Entiende tu proyecto completo — lee archivos, escribe código, ejecuta comandos, corre tests y hace deploys. Es como tener un desarrollador senior sentado a tu lado que conoce cada línea de tu codebase.

No necesitas copiar y pegar código entre el chat y tu editor. Claude Code trabaja directamente en tu proyecto — abre archivos, hace cambios y verifica que todo funcione.

Para qué es perfecto

  • Construir apps y features completas — desde cero o sobre código existente.
  • Debugging — encuentra y corrige bugs analizando el código real.
  • Refactoring — reorganiza código, renombra variables, extrae componentes.
  • DevOps — configurar deploys, CI/CD, variables de entorno.
  • Automatización — scripts, tareas programadas, integraciones con APIs.

Dónde usarlo

  • Terminal — abre tu terminal y escribe claude.
  • VS Code — extensión integrada en tu editor.
  • JetBrains — plugin para WebStorm, IntelliJ, etc.

Lo que no puede hacer

  • No puede interactuar con interfaces gráficas (usa Computer Use para eso).
  • No es ideal para preguntas rápidas sin contexto de proyecto.
  • Necesita un proyecto o directorio para trabajar.

Cuándo elegir Claude Code

Si la tarea involucra código, archivos o tu proyecto de desarrollo — Claude Code es la opción. No importa si es un bug, una feature nueva o un deploy. Si vive en tu codebase, Claude Code lo maneja mejor que el chat y Computer Use combinados.

06 primeros pasos

Cómo empezar hoy

No necesitas experiencia técnica para probar las tres formas. Empieza por la que más te llame la atención:

Probar el Chat

Abre claude.ai en tu navegador. No necesitas instalar nada. Escribe cualquier pregunta y empieza a conversar. La versión gratuita funciona perfecto para probar.

Probar Computer Use

Descarga Claude Desktop y activa Computer Use en la configuración. Pídele que haga algo simple — como buscar algo en Google o llenar un formulario — y observa cómo lo hace.

Probar Claude Code

Abre tu terminal y escribe npm install -g @anthropic-ai/claude-code para instalar. Luego navega a cualquier carpeta de proyecto y escribe claude para empezar.

El mejor consejo

No intentes aprenderlo todo de golpe. Empieza con el chat para las cosas del día a día. Cuando te sientas cómodo, prueba Computer Use para tareas visuales. Y cuando tengas un proyecto de desarrollo, abre Claude Code. Cada modo se vuelve natural con el uso — no necesitas ser experto desde el primer día.
