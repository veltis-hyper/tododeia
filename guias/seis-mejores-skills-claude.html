skill 1 · la fábrica

Skill Creator · arma habilidades sin pelearte con archivos

01Skill Creator

Plugin oficial · marketplace claude-plugins-official

La fábrica de habilidades.

Le platicas a Claude qué quieres que haga, como si fuera tu compa, y te arma la habilidad lista para usar. Cero pelearte con archivos raros bajados de internet.

Instala Skill Creator desde Claude Code

/plugin install skill-creator@claude-plugins-official
Copiar comando

Nota: Se escribe dentro de Claude Code, no en la terminal. Si no aparece, revisa que estés en la versión 2.1.86 o superior.

skill 3 · trabajo en piezas

GSD · parte el trabajo en pedacitos chiquitos

03GSD · Get Shit Done

Subagentes paralelos · npx

Parte el trabajo en pedacitos chiquitos, cada uno con su Claude fresco.

Cuidado con este: úsalo solo cuando la verdad sea necesario. Toma un trabajo grande, lo divide en piezas y le asigna una instancia fresca de Claude a cada una. Se acabó eso de que a la media hora se le olvidó qué le pediste.

Instala GSD globalmente

npx get-shit-done-cc --claude --global
Copiar comando

Nota: Se corre en la terminal. Cada subagente arranca con su propio contexto, así que no se contaminan entre sí.

04/review

Built-in Claude Code 2.1.86+

Revisión de código nivel senior. Built-in. Gratis.

Ni lo tienes que instalar — ya está dentro de Claude Code. Antes de mandar cualquier cosa como construido, le picas /review y te revisa todo tu proyecto como un programador profesional. Bugs, errores, estructuras, todo.

Úsalo dentro de Claude Code

/review
Copiar comando

Nota: No requiere instalación. Si tu Claude Code no lo reconoce, actualízalo a la versión 2.1.86 o superior.

skill 5 · sesiones que duran horas

Context Mode · aplasta toda la basura de tu chat

05Context Mode

56 KB → 299 bytes · mksglu/context-mode

Aplasta toda la basura que llena tu chat para que la sesión no se muera.

Logs, datos, ruido que nadie ocupa — Context Mode lo comprime y lo deja chiquito para que ya no queme tu cuenta. Lo que era 56 KB se vuelve 299 bytes. Tu sesión dura 3 horas en lugar de morirse a los 30 minutos.

Agrega el marketplace y luego instala

/plugin marketplace add mksglu/context-mode /plugin install context-mode@context-mode
Copiar comando

Nota: Las dos líneas se pegan dentro de Claude Code, una después de la otra. Reinicia la sesión al terminar.

skill 6 · memoria permanente

Claude Mem · a Claude ya no se le olvida nada

06Claude Mem

thedotmack/claude-mem

Memoria permanente. A Claude ya no se le olvida nada.

Mi favorita, la verdad — me cambió la vida. Ya no le explicas a Claude en qué estabas trabajando cada vez que abres una sesión: recuerda todo solito. Captura lo que pasa, genera resúmenes con IA y los recupera cuando vuelves al proyecto.

Instala Claude Mem en tu terminal

npx claude-mem@latest init
Copiar comando

Nota: Se corre en terminal. Reinicia Claude Code después de instalar y abre http://localhost:37777 para ver el visor web de tu memoria.

Qué instalar primero (y por qué en ese orden)

No instales las 6 el mismo día. Cada una cambia cómo trabajas con Claude, y el orden importa para que no te revuelvas. Estas son tres rutas según en qué punto estés hoy.

Apenas instalaste Claude Code

Claude Mem→Skill Creator→/review

Primero le das memoria para que no pierda contexto, después la fábrica de habilidades para empezar a personalizarlo, y /review como red de seguridad antes de mandar cualquier cosa como terminada.

Ya usas Claude Code a diario

Superpowers→Context Mode→Claude Mem

Si ya tienes ritmo, Superpowers te quita errores en la planeación, Context Mode te deja sesiones que duran horas en lugar de minutos, y Claude Mem cierra el círculo para que nunca pierdas un proyecto entre sesiones.

Construyes cosas grandes con Claude

GSD · Get Shit Done→Superpowers→/review

GSD parte el trabajo en piezas con su propio Claude cada una, Superpowers obliga a planear antes de programar, y /review revisa todo como un senior antes de aceptar el código. Las tres juntas evitan los rebotes típicos de un proyecto grande.
