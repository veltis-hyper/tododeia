Tu segunda cabeza con Claude + Obsidian

Toda conversación buena que tienes con Claude se borra cuando cierras el chat. Con este plugin, todo queda guardado para siempre en una carpeta de notas — y Claude la va llenando, conectando y acomodando solito.

Plugin oficial · marketplace de Claude Code

Ver repo en GitHub

Explicado fácil

Obsidian es una app gratis que abre una carpeta de tu compu como si fuera un cuaderno. Cada nota es un archivo chiquito de texto — y se pueden conectar entre sí como páginas de Wikipedia.

Este plugin (claude-obsidian) le enseña a Claude Code a leer esa carpeta, escribir en ella, y acomodar todo lo que vas aprendiendo. Tú no tocas nada — solo le dices qué quieres y él se encarga.

Resultado: cada vez que cierras Claude, tus ideas no se pierden. Se quedan escritas en tu compu para siempre, listas para que Claude las use la próxima vez.

02 instalación fácil

Opción 1 — pega este prompt y listo

No tienes que clonar repos, ni escribir comandos raros, ni configurar nada. Pega este prompt en Claude Code dentro de tu carpeta de Obsidian — él instala el plugin, arranca la estructura y te explica cómo seguirle.

Prompt todo-en-uno

Copia, pega en Claude Code y dale enter. Él se encarga del resto.

Copiar
Instala el plugin claude-obsidian desde https://github.com/AgriciDaniel/claude-obsidian en esta carpeta.

Pasos:
1. Corre: claude plugin marketplace add AgriciDaniel/claude-obsidian
2. Corre: claude plugin install claude-obsidian@claude-obsidian-marketplace
3. Cuando termine, corre /wiki para crear la estructura inicial de mi vault.
4. Resúmeme en español qué comandos quedaron disponibles (/save, /autoresearch, /canvas, ingest) y cómo empiezo a usarlos.

Importante:
- No escribas notas mías todavía — primero confirma que el plugin quedó bien instalado.
- Si algo falla en la instalación, pausa y dime exactamente qué error salió antes de seguir.

04 primer arranque

Crea tu cabeza con /wiki

Sigues dentro de Claude Code. Escribe este comando y dale enter:

Arranque inicial

/wiki
Copiar comando

Claude te arma la estructura completa: cuatro carpetas, un índice (index.md) y un archivo de memoria rápida (hot.md). Ya quedó tu segunda cabeza.

concepts/

Las ideas grandes — lo que estás aprendiendo.

sources/

De dónde salió cada cosa — libros, posts, videos.

entities/

Personas, empresas, productos que aparecen en tus notas.

sessions/

Las pláticas que tuviste con Claude, archivadas.

No necesitas acordarte de ninguna de esas carpetas. Claude es quien las llena — tú solo le das material.

05 día a día

Los 3 comandos que vas a usar siempre

Estos son los que vale la pena aprenderte. Con estos tres ya tienes el 90%.

/save

Después de una conversación buena, Claude lee todo, saca las ideas clave y las guarda como páginas conectadas en las carpetas correctas.

/autoresearch [tema]

Claude hace de 3 a 5 rondas de búsqueda en internet sobre lo que le pediste, arma páginas con citas y las pega a lo que ya tienes.

/canvas [descripción]

Claude te dibuja un tablero visual (flowchart, línea del tiempo o mapa mental) con los pedazos de tu wiki que pediste.

06 el loop que lo hace mágico

Mete material crudo, deja que Claude lo digiera

Este es el truco que convierte esto en tu segunda cabeza real. Cada vez que encuentres algo bueno — un PDF, un artículo, un transcript, notas de junta, un video transcrito — haces dos cosas:

  1. Arrastras el archivo a la carpeta .raw/ de tu vault. Esa carpeta nunca la tocas a mano — es tu archivo original intacto.
  2. Le dices a Claude:

Digerir un archivo nuevo

ingest [nombre del archivo]
Copiar comando

Claude lo lee completo, crea entre 8 y 15 páginas conectadas, saca conceptos y entidades, y lo amarra con todo lo que ya tenías.

Lo más útil: si algo de lo nuevo se contradice con notas viejas, Claude te lo marca con [!contradiction]. Así sabes cuándo cambiaste de opinión o cuándo dos fuentes no están de acuerdo.

07 consultar

Cómo le preguntas a tu segunda cabeza

Cuando quieras recordar algo que ya le enseñaste — o ver todo lo que sabes sobre un tema — solo pregúntale a Claude. En inglés o en español, como prefieras:

En inglés

what do you know about [tu tema]?
Copiar comando

En español

qué sabes sobre [tu tema]
Copiar comando

Claude lee la memoria rápida (hot.md), revisa el índice y te responde citando tus propias notas, no lo que aprendió en su entrenamiento. Es tu conocimiento, devuelto de forma ordenada.

08 opcional

Personalizar autoresearch (si ya le agarraste el modo)

Cuando /autoresearch investiga en internet, busca en fuentes generales. Si quieres que priorice ciertos lugares — PubMed si eres doctor, blogs de founders si tienes startup, papers académicos, foros específicos — edita este archivo dentro de tu vault:

Archivo de preferencias

skills/autoresearch/references/program.md
Copiar comando

No es obligatorio. Déjalo tal cual al principio y cámbialo solo si notas que Claude no está pescando las mejores fuentes para tu tema.

Regla de oro: nunca toques una carpeta, un tag ni un link a mano. Tú solo metes material crudo a .raw/ y le dices ingest. Todo lo demás lo hace Claude.
