Animaciones

proyecto operativo para crear videos con Remotion + Codex desde cero. ejecutas un solo comando y el sistema instala dependencias, prepara el proyecto, levanta preview y te deja listo para iterar en vivo.

Cómo te vas a sentir y qué va a pasar

Si vienes empezando

vas a seguir una ruta guiada paso a paso: abrir terminal, copiar un comando, esperar instalación y ver la preview de Remotion corriendo en tu navegador.

Si ya eres experto

tienes un bootstrap idempotente para iterar rápido: instala solo lo faltante, reusa setup existente y entra directo al flujo de construcción de videos.

Paso 1: abre la terminal

macOS

presiona command + space, escribeterminal y ábrelo.

Windows

busca PowerShell, clic derecho y ejecuta como administrador.

Linux

usa Ctrl + Alt + T o abreTerminal desde aplicaciones.

Paso 2: ejecuta un solo comando

ejecuta el comando según tu sistema. esto clona/actualiza el repotododeia-animaciones y corre bootstrap automáticamente.

macOS / Linux / WSL

bash <(curl -fsSL https://raw.githubusercontent.com/Hainrixz/tododeia-animaciones/main/install.sh)
Copiar comando

Windows (PowerShell)

irm https://raw.githubusercontent.com/Hainrixz/tododeia-animaciones/main/install.ps1 | iex
Copiar comando

Paso 3: qué instala automáticamente

  • Codex CLI (si ya lo tienes, se salta).
  • dependencias base: git, node, npm y cloudflared.
  • skills necesarias para video: video-generator y remotion-best-practices.
  • proyecto inicial de Remotion en output/agent-video-starter.
  • preview local + URL pública por túnel para revisión.
al finalizar instalación, Codex se lanza con un prompt inicial para guiarte en la creación del video. tú solo describes la idea y vas iterando cambios.

Paso 4: flujo recomendado en Codex

  1. describe el video: objetivo, duración, formato (16:9 o 9:16), estilo visual.
  2. revisa preview local/túnel y marca cambios concretos por escena.
  3. itera hasta cerrar narrativa, ritmo y transiciones.
  4. pide export solo cuando estés conforme con el resultado.

Si algo falla: checklist rápido

Error de permisos

ejecuta terminal como administrador. en macOS/Linux, al escribir contraseña no se ven caracteres: escribe y presiona Enter.

Puerto 3000 ocupado

corre con otro puerto: --port 3001.

No abre Codex autenticado

ejecuta codex login y vuelve a correr el comando.

Fallo en git pull

si el instalador detecta cambios locales sin commit, guárdalos/commitéalos y reintenta.

Modo manual (si ya estás dentro del repo)

si ya tienes el repo abierto y solo quieres correr bootstrap local:

Si ya clonaste el repo (Bash)

bash scripts/bootstrap.sh
Copiar comando

Si ya clonaste el repo (PowerShell)

powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
Copiar comando
