qué es · 30 segundos

awesome-gpt-image-2 explicado en serio

Es una colección comunitaria de 4,430 prompts curados para generar imágenes con OpenAI GPT Image 2 (codename duct-tape) — el modelo nuevo de OpenAI que renderiza texto perfecto en varios idiomas, mantiene consistencia entre imágenes y saca ilustración nivel comercial sin tanto retoque manual. Vive en GitHub bajo licencia CC BY 4.0, lo mantiene la gente de YouMind, y un GitHub Action lo regenera cada 4 horas jalando los prompts nuevos del CMS de la comunidad.

Tres datos que importan: nació el 16 de abril de 2026, lleva 4,500+ stars en menos de un mes, y trae el README en 16 idiomas, incluyendo español LatAm en el archivo README_es-419.md. Es la fuente que vamos a pasarle a Claude.

el truco · repo → claude → chatgpt

No copies el prompt directo: pásalo por Claude primero

La trampa que casi nadie te cuenta: los prompts del repo son geniales como base, pero genéricos. Si los pegas tal cual en ChatGPT, sale una imagen genérica. El truco es pasarlos por Claude para que los adapte a tu negocio, tu producto, tu tono — y después los pegas en ChatGPT.

  1. 01

    Instala Claude Desktop

    Bájala gratis en claude.ai/download (Mac o Windows). Necesitas la versión de escritorio porque puede abrir URLs y leer el README directo. La versión web no jala igual para este flujo.

  2. 02

    Pásale a Claude la URL del README en español

    Copia uno de los starter prompts de abajo y pégalo en Claude. Ya trae la URL del README es-419 — Claude la lee, te resume las 10 categorías y te pregunta tu negocio.

  3. 03

    Personaliza y pega en ChatGPT

    Claude te devuelve un prompt afinado a tu marca, producto y tono. Copias ese prompt, lo pegas en ChatGPT (asegúrate que esté en modo GPT Image 2) y sale la imagen.

URL exacta del README es-419 que le vas a pasar a Claude: https://raw.githubusercontent.com/YouMind-OpenLab/awesome-gpt-image-2/main/README_es-419.md
