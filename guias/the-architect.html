01 explicado fácil

Qué es The Architect

Imagina que quieres construir una casa. Antes de construir, necesitas un plano — un dibujo que dice dónde va cada pared, cada puerta, cada ventana. Sin ese plano, el constructor no sabe qué hacer.

The Architect es quien te hace ese plano, pero para software. Le describes tu idea y te genera un archivo con todo lo que necesita Claude Code para construirlo solo — sin preguntarte nada más.

Es un proyecto gratuito y open source que vive dentro de Claude Code. Lo descargas, lo abres con Claude y listo — ya tienes a tu arquitecto personal.

02 paso a paso

Cómo funciona

01

Le dices qué quieres construir

Una SaaS, una app, una página, un agente — lo que sea. Solo descríbelo con tus palabras.

02

Te hace preguntas sobre tu proyecto

No son preguntas genéricas. Te pregunta para qué es, quién lo va a usar y qué necesidad quieres cumplir.

03

Te diseña un plano completo

Con 16 secciones detalladas: base de datos, APIs, frontend, autenticación, pagos, deploy y más.

04

Abres Claude Code y le dices "Construye"

Metes el archivo del plano en un folder nuevo, abres Claude Code ahí y sin preguntarte nada, se pone a construir.

03 instalación

Cómo instalarlo

Tienes dos opciones. Elige la que prefieras:

Opción A — Clonar con Git

Clona el proyecto y abre Claude

git clone https://github.com/Hainrixz/the-architect.git && cd the-architect && claude
Copiar comando

Opción B — Descargar ZIP

Dale click al botón Descargar ZIP de arriba, descomprime el archivo y luego abre Claude dentro del folder:

Abre Claude dentro del folder descargado

cd ~/Downloads/the-architect-main && claude
Copiar comando

05 el atajo

Just Build It

¿No quieres contestar muchas preguntas?

Solo escribe Just Build It o Solo constrúyelo y The Architect elige las mejores opciones por ti. Te genera el plano completo con las decisiones más óptimas para tu tipo de proyecto.

06 recomendaciones

Tips

Sé específico con tu idea

No digas "quiero una app". Di "quiero una app de delivery de comida para restaurantes locales con pagos con Stripe". Entre más detalle le des, mejor plano te hace.

Revisa el plano antes de construir

El plano es tu oportunidad de ajustar todo antes de que Claude Code empiece. Léelo, cambia lo que no te convenza y luego sí dale construir.

Usa el plano como tu CLAUDE.md

Mete el archivo del plano directamente en la raíz de tu proyecto nuevo. Claude Code lo va a leer automáticamente como instrucciones.
