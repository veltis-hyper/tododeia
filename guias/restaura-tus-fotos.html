01 intro

Qué Es NanoBanana y Para Qué Sirve

NanoBanana es un MCP server que conecta Claude con Google Gemini para generar y restaurar imágenes.

En vez de subir tus fotos a una app externa, le das la foto directamente a Claude Code y él usa NanoBanana para procesarla con inteligencia artificial de Google. El resultado: fotos en resolución 4K, con textura de piel natural, iluminación profesional y aspecto de fotografía real.

02 api key

Consigue Tu API Key de Gemini (Gratis)

Cómo hacerlo:

  1. Ve a Google AI Studio (aistudio.google.com)
  2. Inicia sesión con tu cuenta de Google
  3. Haz clic en "Get API Key" o "Create API Key"
  4. Copia la key y guárdala en un lugar seguro

Importante:

La API key de Gemini es gratuita con límites generosos para uso personal. No compartas tu key con nadie y no la subas a repositorios públicos.

04 el prompt

El Prompt de Restauración Profesional

Cómo usarlo:

  1. Abre Claude Code con NanoBanana ya instalado
  2. Pasa la ruta de tu foto (o pégala directo en el chat)
  3. Copia y pega el prompt de abajo
  4. Claude procesa la imagen y te entrega el resultado en HD

Prompt de Restauración Fotográfica

Este prompt está diseñado para obtener resultados ultra-realistas — sin aspecto de IA, sin estilos de ilustración

Copiar
Aplica restauración fotográfica ultra-realista con textura de piel natural, detalles precisos y un aspecto fotográfico profesional. Salida en resolución 4K con enfoque nítido pero natural, iluminación cinematográfica moderna, iluminación volumétrica sutil, gradación de color profesional, profundidad de campo sutil y HDR.
La salida debe verse como una fotografía real tomada con una cámara de cine de alta gama con una estética de foto en crudo (raw). No generada por IA, no ilustrada, no excesivamente nítida, no con aspecto plástico.
No aplicar ninguna reinterpretación creativa, cambios de estilo, alteraciones de identidad, remodelación facial ni características exageradas. Sin estilos de caricatura, pintura ni ilustración. Sin sobre-enfoque, desenfoque, ruido, grano de película ni artefactos JPEG.

Pro tip:

Puedes combinar el prompt con instrucciones adicionales. Por ejemplo: "Restaura esta foto y ajusta la iluminación para que se vea como golden hour". NanoBanana entiende contexto y puede adaptar el resultado.

05 tips

Tips Para Mejores Resultados

1

Modelo NB2

El modelo por defecto (Gemini Flash) — combina velocidad con calidad 4K. Ideal para la mayoría de fotos.

2

Modelo Pro

Usa el modelo Pro para composiciones complejas que necesitan más análisis y razonamiento.

3

Aspect Ratios

Soporta 1:1, 4:3, 16:9, 9:16 y 21:9. Especifica el ratio si necesitas un formato exacto.

Dónde se guardan las imágenes:

Por defecto, las imágenes restauradas se guardan en ./nanobanana-output/ dentro de tu directorio actual. Puedes cambiar esto configurando la variable de entornoIMAGE_OUTPUT_DIR.
