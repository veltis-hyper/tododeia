Por qué estas 5, y no otras

Si haces contenido con Claude Code, hay un montón de skills nuevas saliendo cada semana. La mayoría son chistosas pero no mueven la aguja. skill 1 · video desde un prompt

Hyperframes · armar videos completos sin abrir un editor

01Hyperframes

Skill · creado por HeyGen

Videos completos desde un solo prompt.

Le picas un prompt y Claude te arma el video con animaciones, gráficos y subtítulos. Todo en un solo prompt — sin abrir Premiere, CapCut ni timeline alguno. Es renderizado programático, así que el resultado es consistente y lo puedes regenerar las veces que quieras.

Para qué sirve: Cuando quieres prototipar un reel, un explainer o una intro corta y no tienes tiempo de editar a mano.

Instala Hyperframes

git clone https://github.com/heygen-com/hyperframes ~/.claude/skills/hyperframes
Copiar comando

Nota: El README del repo te dice si tu versión de Claude Code prefiere instalarlo como plugin o como skill manual. Te dejamos el comando más universal.

Ver guía completa de HyperframesRepo en GitHub

skill 2 · investigación en vivo

Last 30 Days · qué está diciendo la gente esta semana

02Last 30 Days

Skill · creado por mvanhorn

Lo que la gente está diciendo HOY, no lo que tú crees.

Le pones tu tema y se mete a Reddit, X, YouTube, Hacker News y GitHub a jalarte lo que la gente está diciendo los últimos 30 días. Ya no inventas ideas. Las sacas del feed real, con la voz que está sonando esta semana.

Para qué sirve: Cuando arrancas un guion, un post o un proyecto y quieres validar primero qué está pegando en tu nicho.

Instala Last 30 Days

git clone https://github.com/mvanhorn/last30days-skill ~/.claude/skills/last30days
Copiar comando

Nota: Funciona como skill estándar. Después de clonarlo, reinicia tu sesión de Claude Code para que la cargue.

Ver guía completa de Last 30 DaysRepo en GitHub

skill 3 · imágenes en sesión

Claude Banana · imágenes con Nano Banana sin salir de Claude

03Claude Banana

Plugin · usa Gemini 2.5 Flash Image

Imágenes con Nano Banana de Google, sin salir de Claude Code.

Conecta Claude con Nano Banana — el modelo de imagen de Google (Gemini 2.5 Flash Image). Le pides una thumbnail, un carrusel para Instagram o una imagen para tu post y te las arma directo en la sesión. Sin abrir otra herramienta.

Para qué sirve: Cuando necesitas visuales rápidos para acompañar un post, un reel o una idea sin abrir Photoshop ni Figma.

Instala Claude Banana

git clone https://github.com/Hainrixz/claude-banana ~/.claude/plugins/claude-banana
Copiar comando

Nota: Vas a necesitar tu API key de Google AI Studio (tiene tier gratis). La guía interna te lo explica paso a paso.

Ver guía completa de Claude BananaRepo en GitHub

skill 4 · desglose de virales

Claude Video Vision · entender por qué pegó un reel

04Claude Video Vision

Skill · creado por jordanrendric

Le aventas el reel viral y Claude te dice por qué pegó.

Le mandas el reel que quieres replicar y Claude se lo ve frame por frame. Le pides el desglose: hook, tomas, ritmo, transiciones. Literalmente le copias la fórmula al que ya pegó — pero con datos, no a ojo.

Para qué sirve: Cuando ves un reel que está pegando en tu nicho y quieres entender exactamente por qué, antes de replicarlo.

Instala Claude Video Vision

git clone https://github.com/jordanrendric/claude-video-vision ~/.claude/skills/claude-video-vision
Copiar comando

Nota: Necesitas Python y ffmpeg instalados para que extraiga los frames del video. El README explica los requisitos.

Repo en GitHub

skill 5 · la que nadie te cuenta

Apify · data cruda de Instagram y Facebook

05Apify

MCP · scrapers de redes sociales

Los datos crudos del que está pegando en Instagram y Facebook.

Le picas y agarra los posts de Instagram, Facebook y otras plataformas — datos crudos, no estimados. Likes reales, comments reales, copy real del que está pegando en tu nicho. Ya no copias a ojo: copias con data.

Para qué sirve: Cuando quieres analizar a tu competencia o a un creator que está creciendo y necesitas los números reales detrás del feed.

Conecta Apify como MCP en Claude Code

claude mcp add apify -- npx -y @apify/actors-mcp-server
Copiar comando

Nota: Vas a necesitar una cuenta de Apify (tiene plan gratis). Crea un API token y pásalo como variable de entorno — el README te dice cómo.

¿Cuál vas a probar primero?

Si apenas estás arrancando, empieza por Last 30 Days para que tus ideas vengan del feed real, y por Claude Banana para tener visuales rápidos. Si ya publicas a diario, súmale Claude Video Vision para entender por qué pegan los reels que ves. Y cuando quieras pasar de copiar a ojo a copiar con data, ahí entra Apify con la info cruda de Instagram y Facebook. Hyperframes lo dejas para cuando quieras probar videos generados desde un prompt.
