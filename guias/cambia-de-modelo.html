Cambia de Modelo Cuando Claude Se Siente Lento

Si sientes que Claude a veces no es muy inteligente, no te lo estás imaginando. Los modelos más nuevos se saturan y a veces solo necesitas bajar a un modelo anterior para tener mejores resultados — y de paso gastar menos tokens.

Los modelos anteriores gastan menos tokens

Esto significa que además de tener mejores resultados cuando los modelos nuevos están saturados, también estás ahorrando en tu cuenta de Claude. Doble beneficio.

01 en la app

Cambia de Modelo en claude.ai

Si usas Claude en la app o en la página web, el cambio es directo desde el selector de modelo. Vas a ir a la parte de modelos en la esquina derecha de tu pantalla:

  1. Abre claude.ai y abre o crea un chat
  2. Busca el selector de modelo en la parte derecha, en la esquina — dale clic
  3. Busca donde dice "Más modelos" — ahí están los modelos anteriores
  4. Selecciona un modelo anterior: Sonnet 4.5, Opus 4.5 o Haiku

Sonnet 4.5

Rápido y eficiente para código

Opus 4.5

Potente para razonamiento profundo

Haiku

Ultra rápido y barato en tokens

Tip: Cuando sientas a Claude lento con los modelos más nuevos, usa los modelos anteriores y vas a ver una diferencia impresionante. El modelo que selecciones se queda activo para esa conversación.

02 en la terminal

Cambia de Modelo en Claude Code

Si usas Claude en la terminal (Claude Code), tienes dos formas de cambiar de modelo — una dentro de la sesión y otra al iniciar:

Dentro de una sesión activa — usa /model

Cambiar a Sonnet 4.5

/model claude-sonnet-4-5-20250929
Copiar comando

Cambiar a Opus 4.5

/model claude-opus-4-5-20251101
Copiar comando

Cambiar a Haiku 4.5

/model claude-haiku-4-5-20251001
Copiar comando

Al iniciar Claude Code — usa --model

Iniciar con Sonnet 4.5

claude --model claude-sonnet-4-5-20250929
Copiar comando

Iniciar con Opus 4.5

claude --model claude-opus-4-5-20251101
Copiar comando

Verifica qué modelo estás usando

La barra de estado de Claude Code siempre muestra el modelo activo. Búscala en la parte inferior de tu terminal:

~/mi-proyecto · sonnet-4 · 1M ctx · 67% ■■■■■■░░

Si ves un modelo nuevo y sientes que está lento, cámbialo con /model claude-sonnet-4-5-20250929.

03 subagentes

Fija el Modelo en un Subagente

Si usas subagentes en Claude Code (archivos .claude/agents/*.md), puedes fijar el modelo en el frontmatter del archivo. Así ese agente siempre usa el modelo que tú definas, sin importar qué modelo esté activo en tu sesión principal.

Ejemplo de subagente con modelo fijo

Archivo .claude/agents/mi-agente.md

Copiar
---
model: sonnet
---

Eres un agente especializado en revisión de código.
Analiza el código del proyecto y sugiere mejoras.
Tip: Usa model: haiku para agentes de tareas simples (documentación, clasificación) y model: opus solo para agentes que hacen trabajo complejo (arquitectura, investigación profunda).
