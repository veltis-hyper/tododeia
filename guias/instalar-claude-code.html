Instalar Claude

guía en español para instalar Claude en tu computadora. la forma más fácil es descargar la app de escritorio. si eres desarrollador, también puedes instalar Claude Code por terminal. aquí cubrimos ambos caminos paso a paso.

Qué vas a aprender

  • Descargar la app de Claude Desktop — la forma más rápida de empezar (Mac y Windows).
  • Ver los planes disponibles — Free, Pro y Max.
  • Qué incluye — Claude, Claude Code y Claude co-work, todo desde una sola app.
  • Instalar Claude Code por terminal — alternativa para desarrolladores.

01 recomendado

Descarga la app de Claude

la forma más sencilla de usar Claude es descargar la app de escritorio. funciona en Mac y Windows, y el sitio detecta tu sistema operativo automáticamente. descarga, instala y listo.

Descargar Claude DesktopVer planes y precios

con el plan Free puedes empezar sin pagar. si necesitas más uso, revisa Pro o Max.

02 qué incluye

3 herramientas en 1

al instalar la app de Claude Desktop tienes acceso a todo esto:

Claude

el asistente de IA. chat directo para preguntas, análisis, escritura, investigación y más.

Claude Code

agente de código en terminal. lee tu proyecto, edita archivos, corre comandos y propone cambios.

Claude co-work

coding colaborativo. Claude trabaja en segundo plano mientras tú sigues con lo tuyo.

03 alternativa CLI

Instalación por terminal

si prefieres instalar Claude Code directamente desde la terminal, copia el comando de tu sistema operativo y ejecútalo.

macOS / Linux / WSL

curl -fsSL https://claude.ai/install.sh | bash
Copiar comando

Windows — PowerShell

irm https://claude.ai/install.ps1 | iex
Copiar comando

Windows — CMD

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

si usas Windows, instala primeroGit for Windows .

04 requisitos

Antes de instalar (check rápido)

estos requisitos aplican principalmente si instalas por terminal (CLI).

  • sistema operativo compatible: macOS 13+, Windows 10 1809+ o Ubuntu 20.04+ / Debian 10+ / Alpine 3.19+.
  • mínimo 4 GB de RAM y conexión a internet.
  • en Windows necesitas Git for Windows.
  • Claude Code solo funciona en países soportados por Anthropic.

05 primer arranque

Primer arranque y login

Abrir Claude Code en tu proyecto

cd tu-proyecto && claude
Copiar comando

Crear carpeta nueva e iniciar

mkdir mi-proyecto && cd mi-proyecto && claude
Copiar comando
  1. al correr claude, se abrirá el flujo de autenticación.
  2. elige cómo iniciar sesión (Claude App, Console, Bedrock o Vertex AI).
  3. termina el login y ya puedes empezar a pedir tareas en tu proyecto.

06 verificación

Doble check: ¿quedó bien instalado?

Verifica versión instalada

claude --version
Copiar comando

Diagnóstico rápido

claude doctor
Copiar comando
  • si ves la versión en pantalla, la instalación está bien.
  • si claude doctor no marca errores críticos, tu entorno está listo.

07 comandos útiles

Comandos rápidos

  • /init — crea guía del proyecto (CLAUDE.md).
  • /help — muestra ayuda y comandos disponibles.
  • /clear — limpia el contexto actual del chat.
  • /compact — resume conversación para usar menos contexto.
  • /review — pide revisión de cambios.
