01 qué es computer use

Tu agente con ojos y manos

Claude ahora puede ver tu pantalla, mover tu mouse, hacer clic en botones y escribir en cualquier campo. No importa si es un navegador, una hoja de cálculo, un CRM viejo o una app de escritorio — si tú puedes usarla, Claude también.

Esto se llama Computer Use y está disponible como research preview en macOS, tanto en Claude Desktop (Cowork) como en Claude Code.

Sin Computer Use

Claude solo puede leer y escribir archivos. Para conectar apps necesitas APIs, integraciones o MCPs. Las aplicaciones sin API quedan fuera de su alcance.

Con Computer Use

Claude ve tu pantalla, hace clic en botones, navega menús, llena formularios. Cualquier app que tú puedas usar, Claude también — sin necesidad de API.

02 para qué sirve

Apps sin API, automatizadas

Esas aplicaciones viejas que tienes que no se conectan a nada, que no tienen APIs, que nada más puedes picarle tú los botones. Ahora Claude pica esos botones por ti, llena formularios, navega menús, hace todos los trabajos repetitivos que tú haces en tu computadora.

Formularios repetitivos

Apps de gestión, CRMs viejos, sistemas internos. Claude los llena por ti.

Navegación de menús

Software con menús profundos y muchos clics. Claude navega hasta donde necesitas.

Migración de datos

Copiar datos de una app vieja a una nueva, pantalla por pantalla, sin errores.

Reportes manuales

Abrir un sistema, extraer números, pegarlos en una hoja de cálculo. Automatizado.

03 testing y qa

Tu tester automático

Si estás construyendo una app o haciendo un proyecto, Claude puede abrirlo, picarle a todo y encontrar errores. En otras palabras, ya es tu tester completo.

  • Navegar todas las páginas y verificar que carguen
  • Hacer clic en cada botón y confirmar que funcione
  • Llenar formularios con datos de prueba
  • Detectar errores visuales (elementos rotos, imágenes que no cargan)
  • Revisar la consola del navegador por errores

QA automatizado con Computer Use

Claude abre tu app, navega cada pantalla y reporta errores visuales o funcionales.

2. Revisa que todos los botones sean clickeables

Genera un reporte con los problemas encontrados y sugerencias de fix.

Tip: Combina Computer Use con Claude Code para que además de encontrar los errores, los arregle automáticamente en tu código.

05 cómo activarlo

Configuración paso a paso

En Cowork (Claude Desktop)

  1. Abre Claude Desktop y ve a Settings
  2. Busca la sección Computer Use
  3. Activa el toggle
  4. Claude te pedirá permisos de accesibilidad (macOS)
  5. Listo — Claude ahora puede ver tu pantalla y controlar tu mouse

En Claude Code (Terminal)

claude --computer-use

Claude Code lanza una sesión con Computer Use habilitado. Claude puede ver tu pantalla y ejecutar acciones directamente.

Importante: Claude puede ejecutar acciones reales en tu computadora. Revisa siempre lo que le pides antes de darle permiso. Empieza con tareas simples para familiarizarte.
